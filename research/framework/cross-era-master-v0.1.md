- 日期：2026-11-04
- 地位：**研究规划与玩法创意存档，不是要求开发 Agent 立即实现的任务清单**
- 当前项目：CoopCraft，Minecraft Java 1.21.1，Fabric；参考仓库 `ThySummer14/coopcraft`
- 与旧资料关系：补充《原始社会完整设计 v1.0》《原始社会研究体系 v1.1》，不覆盖现有开发结果。

## 0. 总目标与防跑偏原则

我们研究的是不同历史条件下人类如何生产、分配、治理、学习和生活，以及社会制度如何在居民行动中维持、变动和重组。Minecraft 展示居民生活与玩家行动，独立社会模拟核心处理资源、关系和可重放历史。

**文明阶段是分析用的理想类型，不是预先排好的单向升级阶梯。** 一座世界可以同时包含技术先进的公共管理社区、技术较低的等级性社区、混合产权聚落；某种社会关系可以产生、延续、转化、衰退或重新出现。螺旋发展不保证最终必定走向同一制度；必须把具体条件、外部联系和历史偶然性放进模型。所谓“进步”要按多维度衡量，不能只用财富或工具等级。

总研究方法：通用问题目录（12维）→ 各历史社会形态的机制画像 → 该形态的一个核心玩法（可闭环）→ 机制实验 → 已知局限和下一形态的接口。严禁“研究一个名词就增加一个独立系统”，先寻找与既有底层对象的复用关系。

## 1. 所有社会形态必须回答的12个标准问题

| ID | 固定研究轴 | 必答问题 | 统一数据接口/可观察结果 |
|---|---|---|---|
| D01 | 历史与生态 | 该形态出现在哪些地区和历史条件？哪些事实存在争议？ | 世界条件、地理、证据标注 |
| D02 | 生产力与技术 | 使用哪些劳动对象、劳动资料、技能和生产组织工具？ | `Resource`, `Technology`, `ProductionTask` |
| D03 | 劳动组织 | 谁劳动、谁协调、工时和劳动成果怎样形成？ | 劳动事件、劳动合同/义务、时间账本 |
| D04 | 产权与生产资料 | 使用、管理、收益、排他、转让和继承等权利如何配置？ | `Asset`, `RightsBundle`, `RuleInUse` |
| D05 | 分配与流通 | 食物、商品、贡赋、市场、货币及储备如何运行？ | 产品批次、交易、配给、价格或非价格分配 |
| D06 | 人口与社会再生产 | 人口如何出生、养育、教育、照料、迁移和死亡？ | 家庭、年龄、照料劳动、人口状态 |
| D07 | 社会分化与阶级 | 职业、身份、财富和生产控制是否形成稳定差异？ | 社会关系、收入/财富、生产控制和依赖 |
| D08 | 治理与政治组织 | 谁制定规则、以何方式取得和维持权威？ | 规范、职位、执行、争议、组织 |
| D09 | 文化与观念 | 知识、习惯、文化认同、宗教/仪式、信息怎样传播？ | 学习网络、文化实践、历史记忆 |
| D10 | 物质生活与空间 | 吃穿住行、建筑、交通、聚落形态是什么？ | 建筑、设施、运输、生活需要 |
| D11 | 矛盾、危机与变迁 | 什么机制使制度再生产？什么条件导致改革、解体、融合或重组？ | 多变量实验、制度变更事件 |
| D12 | 玩家体验与测试 | 该形态最有特色的5~30分钟玩法是什么？玩家怎样影响但不能独断历史？ | 游戏循环、交互、解释、GameTest/回归实验 |

每个维度统一记录四个层级：**[证据]** 可考证的史料/考古/研究；**[解释]** 理论观点及争论；**[假设]** 游戏化抽象与可调参数；**[验收]** 可运行的系统行为。不能把假设包装成历史事实。

## 2. 研究单位不等于社会阶段名称

使用“四轴 + 关系网络 + 历史”的模型：
- A 技术/生产力轴：采集、农业、手工业、机械化、信息化等（允许混合）。
- B 生产关系轴：共同、家庭、奴役、租佃、雇佣、合作等（允许共存）。
- C 治理轴：非正式协调、长老、议事、地方权威、国家行政、企业治理等。
- D 交换/分配轴：分享、贡赋、互惠、市场、配给、计划、混合。
- N 网络与外部联系：迁徙、贸易、技术输入、战争、合作、文化传播。
- H 历史：规则起源、制度稳定性、代际延续、冲突、路径依赖。

社会形态标签应由这些关系的实际组合辅助识别，不作为强制解锁条件。允许社会倒退、混合、跨越某些模式、遭遇外部侵入和保持不同步发展。避免把全球历史化约为西欧单一路线。

## 3. 研究单元划分与每单元的“招牌玩法”

> **以下是内容路线而不是必经进阶。** 采用“社会形态/历史机制专题”而不要求世界依次经历每个单元。

### S0：移动采集与早期共同体（当前聚焦）
- 关键矛盾：资源风险、移动成本、相互依赖、个人自主与社会分配。
- 玩家体验：**加入营地，共同采集/捕鱼/制造石器，探索食物点，参与分享和公仓争议**。
- 核心制度：资源共用、个人工具、公共储备、家庭照料、非正式协调、可变迁徙。
- 特别研究：野外消费与运输、知识不全、共同规则如何从经验产生。
- 完成定义：一个营地在无玩家指令下持续运转；玩家能通过帮助/合作改变关系；至少一条规则实际影响库存并可修订。

### S1：定居、园艺/农业与复杂无国家共同体
- 关键矛盾：长期投入、储藏、土地使用、人口压力、固定设施与迁徙自由。
- 玩家体验：**建设并维护共享灌溉/粮仓/耕地，分配劳动与收成，经历丰歉和家庭土地争议**。
- 核心制度：家庭劳动与公用土地并存、季节性共有或排他权、设施管理。
- 不预设“农业=私有制=国家”；可长期无国家，或出现等级化关系。
- 完成定义：一块土地和一个粮仓可以在不同权利安排下产生不同实际后果。

### S2：早期国家、贡赋经济与存在奴役的社会
- 关键矛盾：大型公共工程、行政征集、贡赋、强制劳动、身份差异、抗争和逃离。
- 玩家体验：**参与一项灌溉/城墙/公共粮仓工程，观察自愿协作、徭役和奴役劳动等不同制度对生活的影响**。
- 核心制度：领地、组织权威、征粮/贡赋、身份与自由差异、武装执行和行政成本。
- 重要警告：奴隶劳动不是所有文明都必经的阶段；早期国家也不都以奴隶劳动为经济基础。模拟强制制度时应清晰展示人的损失与冲突，不把奴役作为无成本的高效升级。
- 完成定义：征集规则真实扣减库存与劳动时间，居民可能配合、抵制、逃离或改变组织关系。

### S3：封建领主制、租佃与多层地方权利
- 关键矛盾：土地控制、农户生产、地租、劳役、公共地、地方权威与保护义务。
- 玩家体验：**经营庄园或以佃农身份生活，分配播种与收获，交纳/征收地租，围绕公地与磨坊形成争议**。
- 核心制度：土地上叠加的多层使用权、领主特权、继承、自治村社、市场混合。
- 完成定义：不同土地和权利安排能改变农户可保留产品、迁徙条件和地方财政。
- 不预设所有地区或时代都有与欧洲一致的封建结构。

### S4：城镇、行会、商贸网络与商业资本
- 关键矛盾：远距离交易、信用、市场接入、价格、商人风险、运输和地方垄断。
- 玩家体验：**开设集市店铺或商队，采购、运送、议价、承担库存风险，与手工业者和行会合作**。
- 核心制度：商店、订单、市场、货币、信用雏形和规制。此处已有“开店”，但开店不等于资本主义占主导。
- 完成定义：商贩必须真实进货、支付运输成本并面对滞销与资金周转约束。

### S5：资本主义生产方式与工业化（用户重点创意）
- 关键矛盾：生产资料与劳动者的分离、劳动力商品化、利润驱动的扩大再生产、竞争、劳资关系。
- 玩家体验：**玩家经营一间可以逐渐扩张的商店/作坊/工厂：采购原料、招聘工人、安排生产、销售商品、计算利润并选择再投资。** 也可作为劳动者、合伙人、合作社成员、消费者参与。
- 核心制度：私有或公司控制的生产资料、雇佣劳动契约、工资、工时、价格、市场需求、资本周转、融资与利润分配。
- 关键研究：商品价值与市场价格的区分；马克思理论的 `c+v+s` 与会计利润不同；价值生产和价值实现/销售不同。
- 完成定义：原料与工资支出、实际劳动、产成品、销售回款、利润与未售库存全部有账；劳资双方利益及权力不对称能形成选择和冲突。

### S6：社会主义的多种组织实验、公共与合作经济
- 关键矛盾：生产资料的实际控制、社会需求与生产计划、激励、信息、参与、监督与资源约束。
- 玩家体验：**经营工人合作社/公共工厂/地区物资调度网络，与成员一起决定生产目标、投资、工时、公共保障与盈余安排**。
- 核心制度：共同或公共所有权、实质参与权、价格与计划的不同组合、预算与监督机制。
- 完成定义：制度不是换个“公有”标签，而是真实改变投资决定权、劳动控制和盈余分配；可模拟多种混合安排、成败与改革。
- 注意：社会主义社会的具体历史与理论路径存在明显争论，应纳入多模型研究，不规定单一制度形态。

### S7：高生产力下的高度社会化合作（高阶段共产主义为理论专题）
- 关键矛盾：需求满足、稀缺与公共资源、自由时间、非强制协调、技术与生态约束。
- 玩家体验：**组织大规模协作工程、知识共享网络和跨地区资源保障，观察较少由谋生压力驱动的劳动生活**。
- 研究边界：高度理想化的未来理论与现实可考证历史不同，必须标注为情境模型，不得宣称拥有确定的历史形态；可以留作远期专题。
- 完成定义：有可实际运行的生产与分配约束，不是“一切无限供应”的创造模式。

### Sx：跨阶段横向专题（任何阶段都可能出现）
- 迁徙与人口、生态危机、技术传播、宗教与文化、市场与非市场互助、征服/殖民、灾难、工艺与艺术、制度改革、社会性别结构、不同地区历史。横向专题仅在某一主线被它阻塞或能显著改善体验时展开，避免无限发散。

## 4. 跨时代复用的底层对象

现有独立 `civilization.simulation` 与 Minecraft 适配优先复用，不应为了本文件建立第二套库存和 AI。

| 领域对象 | 跨时代不变的问题 | 阶段性不同规则 |
|---|---|---|
| Person/Household/Community | 谁生存、劳动、学习、维系关系？ | 家庭结构、居住、身份和权利 |
| Resource/Asset | 使用什么资源和生产资料？ | 共同/家庭/私人/公司/公共使用权 |
| Labor/ProductionTask | 谁以何种时间和工具劳动？ | 自主、互助、徭役、奴役、雇佣、合作 |
| ProductBatch/StockLedger | 产品从哪里来，当前在哪里？ | 分享、地租、贡赋、销售、配给 |
| RightsBundle | 谁能使用、管理、排除和转让？ | 由习惯、规则、合同或权威支撑 |
| Contract/Obligation | 谁对谁承担何种可执行义务？ | 互惠承诺、地租、工资、订单、保障 |
| Exchange/Allocation | 产品为什么转移给另一个人？ | 赠与、互易、市场、征缴、计划 |
| Knowledge/Technology | 谁掌握知识，如何扩散？ | 学徒、行会、学校、工厂训练、公共教育 |
| Institution/Authority | 规则怎样形成、执行和修订？ | 非正式议事、地方法权、国家、企业治理 |
| History/EventLedger | 什么实际改变了，为什么？ | 统一审计、存档、回放和因果解释 |

特别注意：不是所有阶段都需要货币、工资、价格或正式合同。对象可以统一，规则允许相应字段为空或采用非货币表达；不要把后期经济术语套到史前社会。

## 5. 重点玩法创意存档：资本主义的“从一间店到资本循环”

### 5.1 玩家最小可玩循环
1. 选择经营：自营零售店、家庭作坊、雇工工厂、贸易商行等，具有不同资本关系。
2. 投入初始资金或自身积累，取得店面使用权、工具、设备和原材料。
3. 采购原料与货品、签订供货协议，考虑品质、运输、交货和库存成本。
4. 若为生产型企业，聘用劳动者，约定工资、工时、技能需求与劳动条件；工人拥有自主需求和替代机会。
5. 组织真实劳动：生产任务消耗工时、原材料、设备使用寿命，产出实际商品批次。
6. 展示商品、定价、陈列、销售，面对 NPC 居民的购买能力、需求和偏好。
7. 结算销售回款、采购与工资、设备折旧、未售库存、周转资金、租金、利息及税费（制度适用时）。
8. 选择：自我消费、提高工资、扩大产能、改良技术、存货、借贷、合并或转型合作社。政策和居民行动可能改变条件。

玩家始终可以作为**店主、雇员、消费者、供应商、合作社成员**等角色参与，避免把社会模拟写成单一老板视角。

### 5.2 资本循环与理论模型

马克思《资本论》第二卷的货币资本循环：

`M → C(生产资料 MP + 劳动力 LP) ... P ... C' → M'`

- `M`：预付的货币资本；`C`：购入的生产资料与劳动力；`P`：实际生产过程；`C'`：包含新增价值的商品资本；`M'`：销售后实现的货币额。
- 必须区别“已生产”“已出售”“现金已到账”。商品滞销、原料断供、工资支付、赊销都会影响周转。
- 马克思价值分析的记号是 `商品价值 = c + v + s`（不变资本转移价值 + 可变资本/劳动力价值 + 剩余价值），`s/v` 为剩余价值率。这是特定理论框架下的量，不直接等于商店账上的销售利润。
- **会计利润**是实际售价收入扣除应计成本等后的经营结果；它受市场价格、存货计价、固定资产折旧、租金、融资、税费影响。零售套利、经营者本人劳动、资本所得、剩余价值生产与实现、价值转移不能混为一谈。
- 第一版只建立可审计的会计与劳动时间账本，理论上的价值分析可在有足够数据后作为单独的“政治经济学分析视图”，明确采用何种价值与转化假设。

### 5.3 具体系统模块及依赖

| 模块 | 玩家看到什么 | 必须依赖什么 | 初版可以简化什么 |
|---|---|---|---|
| 店面经营 | 上架商品、开关店、货架与仓库 | 真实物资、建筑使用权 | 不必模拟装修评分 |
| 原材料 | 不同品质、交货与缺货 | 生产批次、运输、供应商 | 先做少量原材料 |
| 生产过程 | 机器、工坊、工时与产出 | 劳动任务、技能、设备折旧 | 首版一个工序 |
| 雇佣劳动 | 工资、工时、休息、离职 | 自主 NPC、契约、支付 | 首版只做固定班次 |
| 需求与市场 | 居民购买、价格变化、滞销 | 真实需求、预算和库存 | 局部市场，不全图市场 |
| 收支与资本 | 现金流、成本、利润、再投资 | 货币账本、债权债务 | 首版无复杂证券 |
| 制度与冲突 | 协商、劳资纠纷、监管 | 既有社会规范/组织 | 首版只有一两条规则 |
| 危机与调整 | 库存积压、断料、破产、转型 | 前述完整循环 | 不预设定期金融危机 |

### 5.4 反事实实验
- 相同生产技术，比较一人自营店与雇工企业的利润来源和劳动控制关系；不能因“有店铺”直接判定资本主义。
- 相同工资与生产条件，改变商品需求和售价，观察实际利润与未售库存；不得把生产出来的商品立即算成现金收益。
- 同一企业把一部分利润用于再投资或用于个人消费，比较长期产能、工资支付能力和周转风险。
- 改变劳动者退出机会/其他雇主数量，观察工资、工时、劳动者选择和企业决策。
- 让同一店面在不同产权制度下运行（私人、合作社、公有经营），观察剩余归属与治理，不只换 UI 标签。

### 5.5 此创意的研究优先级
**长期保留，暂不阻塞原始社会阶段。** 为未来资本主义阶段建立专门目录与理论问题清单；基础库存、劳动、权利、契约和事件模型在早期阶段逐步复用，无需现在提前加入工资和货币体系。

## 7. 每阶段的范围与停止规则

### 7.1 三层文献深度
- **L1 总纲层（所有阶段先完成）**：12维索引、5~10条关键参考、3条因果链、1个招牌玩法、5个验证点。先粗扫所有阶段，完成世界观与接口一致性检查。
- **L2 核心设计层（当前重点阶段）**：所需制度与真实经济机制，数据流、玩家交互、NPC决策、失败场景、同型对照实验。
- **L3 专项深研层（遇到机制瓶颈再开）**：如公仓规范形成、资本循环、封建租佃、粮食储存、制度继承等；明示触发原因和产出。

### 7.2 避免卡在某个文明阶段的“研究完成门槛”
- 12维均有一页以内的概述与可信证据来源，不要求每个问题穷尽。
- 已确定可玩闭环、玩家的至少两种参与策略、NPC无玩家时的自主行为。
- 已定义3个关键实验与2个反例，能区分“真的起作用”和“换了个标签”。
- 对跨时代通用对象的接口已说明，且没有需要新建第二套库存/权利/劳动系统的要求。
- 尚存争论与未实现功能有明确记录，**允许冻结为 v1.x 并进入下一阶段研究**。

### 7.3 不属于完成门槛的事
- 模拟社会中所有文化和人格细节；穷举所有生产工具和建筑；覆盖所有地域；推导一种历史必然结局；把全部机制立即做进 Fabric。可以在未来回访。

### 7.4 每次新增研究话题的准入测试
任何新话题必须回答：
1. 属于哪一阶段、哪一个 D 维度？
2. 它帮助解决哪条具体因果链或玩家玩法？
3. 可以复用何种现有系统？
4. 研究终点和可验收产物是什么？
5. 如果暂不研究，当前核心闭环会不会无法成立？
答不清楚就放入待研究池，而不是立刻长篇展开。

## 9. 与当前 Fabric 1.21.1 工程的关系

现有仓库已有模拟核心、资源批次与事件、部分 Minecraft 库存桥接、居民劳动/公仓/规范/照料等机制。**本总纲不要求立即加入工业系统，也不要求迁移 NeoForge。** 当前应维持 Fabric 1.21.1 和现有可测试切片，让开发 Agent 基于最新代码核对状态后增量执行。

早期社会的每一条共享、分工、知识和权利机制，尽量建立足够通用的数据合同，未来才能自然连接店铺、租佃、贡赋、工资、企业和合作经济；但不要为了20个阶段预先编写庞大的空类。

## 10. 初始研究工作安排

1. **立即**：冻结本总纲作为研究目录 v0.1；给 S0 和 S5 建阶段卡。S0 连接已完成的七轮研究，S5 保留本次店铺/资本循环创意。
2. **短期**：为 S1~S4、S6~S7 编写 L1 概览，不深入开发。先检查阶段之间的接口与玩法差异。
3. **同时**：原始社会继续 L2 深化，以玩家日常参与、制度与真实 Minecraft 的联动为验收重点。
4. **后续**：每完成一个可玩实验，再由研究发现决定是否开 L3 专题；已有材料不重复研究。
5. **每轮总结**：新增研究要能回填 12 维索引、阶段卡和设计决策记录，不能只成为一篇孤立长文。

## 12. 长期保留的用户创意（明确记载）

> 在资本主义社会阶段，设计有深度的店铺经营：玩家开设店铺、购买原材料、组织加工、雇佣工人、销售商品，研究资本投入与流通、劳动者和老板之间的关系、工资、利润、剩余价值、再投资及其社会影响。此玩法需要像原始阶段的集体生存、封建阶段的土地/租佃、社会主义阶段的公共生产协调一样，成为该形态的**代表性参与玩法**。研究范围庞大，先立专题、后分解实现；不要提前遗忘或误当成一般买卖系统。
