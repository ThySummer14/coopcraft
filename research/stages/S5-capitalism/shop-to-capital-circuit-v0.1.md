# S5｜资本主义：从店铺经营到资本循环（长期创意 v0.1）

> 本文是用户提出、经初步整理的**长期研究和玩法创意**，不是当前原始社会阶段的立即开发任务。研究单元 S5 并非所有文明的必经终点。  
> 基础架构：CoopCraft / Fabric / Minecraft 1.21.1。  
> 对应维度：D02、D03、D04、D05、D07、D08、D11、D12。  
> 来源：[跨时代研究总纲](../../framework/cross-era-master-v0.1.md)，下文保存原案的玩法和理论细节，避免创意被遗忘。

## 用户明确提出的核心点子

玩家可以在资本主义社会开店售卖商品，并逐渐组织真实经济活动，研究**原材料、资金与资本、加工、劳动者、老板、工资、利润、剩余价值、流通与扩大再生产**的联系。要让玩家能亲身扮演经营者，也允许选择劳动者、消费者或合作社成员的视角。

商店和市场早于资本主义；这一阶段的独特机制应是**生产资料控制、雇佣劳动、资本增殖和再投资**构成的完整循环，不能简单将开店视为资本主义，也不能将会计利润直接等同于剩余价值。

## 5. 重点玩法创意存档：资本主义的“从一间店到资本循环”

### 5.1 玩家最小可玩循环
1. 选择经营：自营零售店、家庭作坊、雇工工厂、贸易商行等，具有不同资本关系。
2. 投入初始资金或自身积累，取得店面使用权、工具、设备和原材料。
3. 采购原料与货品、签订供货协议，考虑品质、运输、交货和库存成本。
4. 若为生产型企业，聘用劳动者，约定工资、工时、技能需求与劳动条件；工人拥有自主需求和替代机会。
5. 组织真实劳动：生产任务消耗工时、原材料、设备使用寿命，产出实际商品批次。
6. 展示商品、定价、陈列、销售，面对 NPC 居民的购买能力、需求和偏好。
7. 结算销售回款、采购与工资、设备折旧、未售库存、周转资金、租金、利息及税费（制度适用时）。
8. 选择：自我消费、提高工资、扩大产能、改良技术、存货、借贷、合并或转型合作社。政策和居民行动可能改变条件。

玩家始终可以作为**店主、雇员、消费者、供应商、合作社成员**等角色参与，避免把社会模拟写成单一老板视角。

### 5.2 资本循环与理论模型

马克思《资本论》第二卷的货币资本循环：

`M → C(生产资料 MP + 劳动力 LP) ... P ... C' → M'`

- `M`：预付的货币资本；`C`：购入的生产资料与劳动力；`P`：实际生产过程；`C'`：包含新增价值的商品资本；`M'`：销售后实现的货币额。
- 必须区别“已生产”“已出售”“现金已到账”。商品滞销、原料断供、工资支付、赊销都会影响周转。
- 马克思价值分析的记号是 `商品价值 = c + v + s`（不变资本转移价值 + 可变资本/劳动力价值 + 剩余价值），`s/v` 为剩余价值率。这是特定理论框架下的量，不直接等于商店账上的销售利润。
- **会计利润**是实际售价收入扣除应计成本等后的经营结果；它受市场价格、存货计价、固定资产折旧、租金、融资、税费影响。零售套利、经营者本人劳动、资本所得、剩余价值生产与实现、价值转移不能混为一谈。
- 第一版只建立可审计的会计与劳动时间账本，理论上的价值分析可在有足够数据后作为单独的“政治经济学分析视图”，明确采用何种价值与转化假设。

### 5.3 具体系统模块及依赖

| 模块 | 玩家看到什么 | 必须依赖什么 | 初版可以简化什么 |
|---|---|---|---|
| 店面经营 | 上架商品、开关店、货架与仓库 | 真实物资、建筑使用权 | 不必模拟装修评分 |
| 原材料 | 不同品质、交货与缺货 | 生产批次、运输、供应商 | 先做少量原材料 |
| 生产过程 | 机器、工坊、工时与产出 | 劳动任务、技能、设备折旧 | 首版一个工序 |
| 雇佣劳动 | 工资、工时、休息、离职 | 自主 NPC、契约、支付 | 首版只做固定班次 |
| 需求与市场 | 居民购买、价格变化、滞销 | 真实需求、预算和库存 | 局部市场，不全图市场 |
| 收支与资本 | 现金流、成本、利润、再投资 | 货币账本、债权债务 | 首版无复杂证券 |
| 制度与冲突 | 协商、劳资纠纷、监管 | 既有社会规范/组织 | 首版只有一两条规则 |
| 危机与调整 | 库存积压、断料、破产、转型 | 前述完整循环 | 不预设定期金融危机 |

### 5.4 反事实实验
- 相同生产技术，比较一人自营店与雇工企业的利润来源和劳动控制关系；不能因“有店铺”直接判定资本主义。
- 相同工资与生产条件，改变商品需求和售价，观察实际利润与未售库存；不得把生产出来的商品立即算成现金收益。
- 同一企业把一部分利润用于再投资或用于个人消费，比较长期产能、工资支付能力和周转风险。
- 改变劳动者退出机会/其他雇主数量，观察工资、工时、劳动者选择和企业决策。
- 让同一店面在不同产权制度下运行（私人、合作社、公有经营），观察剩余归属与治理，不只换 UI 标签。

### 5.5 此创意的研究优先级
**长期保留，暂不阻塞原始社会阶段。** 为未来资本主义阶段建立专门目录与理论问题清单；基础库存、劳动、权利、契约和事件模型在早期阶段逐步复用，无需现在提前加入工资和货币体系。

## 当前结论

**现在只归档，不在S0阶段引入金币、工资、股票或现代企业规则。** 当S5进入L2研究时，再从此提案产生可测试规格和独立开发 Issue。
