## 0. 执行摘要：不做“奴隶时代升级按钮”

S2 研究的是**可持续的资源支配、劳动依附、贡赋征收、行政组织与国家形成**。奴役是可能出现的一类人身关系，不是所有古代国家的主要生产方式，更不是全人类必经的阶段。S0/S1 的公共治理、亲属纽带、易货、混合生计可以继续存在。

### 需锁定的设计决议（ADR-S2）
| ID | 决议 | 不允许的快捷实现 |
|---|---|---|
| D01 | 技术时代与社会关系分轴；S2 是对实际关系的诊断，不是强制阶段 | 粮食>阈值 → 奴隶制 |
| D02 | 血缘、同住、共同供养、照料、经济主体五种联系分开 | `householdId` = 家谱、住所和财产权 |
| D03 | 占有/使用/收益/管理/转让/继承/排他权分开 | 一个 `ownerUuid` 控制一切 |
| D04 | 物质存货、债权、货币计价单位各自独立 | 借条和仓库中都生成同一份粮 |
| D05 | 领导职位与个人分开，权力来源、支持者、监督和强制能力分开 | 首领社交值高就直接有征税权限 |
| D06 | 税收、贡赋、公共分担、租金、捐赠、掠夺有不同依据 | 所有转移都叫“上缴” |
| D07 | 劳役、债务依附、俘虏状态与奴役不可等同 | 一个 `isSlave` 布尔值 |
| D08 | 国家需要持续管辖、专门行政、征收与执行能力；并非建筑等级 | 建成宫殿 → 国家 |
| D09 | 战争、贸易、结盟、迁徙和分裂都可改变治理范围 | 两聚落一接触就无条件合并 |
| D10 | 制度可以失效、改革、终止和反复 | 形态标签只能单调增加 |
| D11 | 先利用已有抽象账本及受控 Minecraft 交接，旧世界默认规则不变 | 重写第二套库存/离线模拟 |
| D12 | 先做可运行的“真实借粮→追债→协商/解除”切片，再扩展国家与战争 | 一次 PR 写完货币、法院、军队、王国 |

## 1. 证据、解释与争议边界

1. **家庭与不平等不是一枚开关**：Kuijt (2024) 强调家庭不平等具有关系性、多维性，考古物质差异并不自动证明社会权力结构；Bentley (2022) 综述亲属系统在史前具有长期多样性。不能把父系、长子独占或固定性别分工预设为必然。  
   - https://doi.org/10.1016/j.jaa.2024.101591  
   - https://doi.org/10.1146/annurev-anthro-041320-021036
2. **家庭、神庙/宫廷等机构持产并存**：芝加哥大学 *Land and Property in Ancient Mesopotamia* 总结两河流域土地买卖、租赁、继承以及宫廷/神庙机构地产；历史时期和地域不同，不能把某一种继承办法推广到全部 S2。  
   - https://isac.uchicago.edu/sites/default/files/uploads/shared/docs/oimp36.pdf  
   - 2024年古巴比伦继子女继承冲突研究：https://doi.org/10.1080/17585716.2024.2380136
3. **记账、债务、支付与铸币不是同一个发明**：美索不达米亚长期使用谷物、白银等作为计价/支付手段；可在无统一铸币时使用契约、实物支付与债务。易货、互惠、信用、实物计价可以共存，“先人人易货，后来突然出现货币”不是可靠的单线历史。  
   - Powell, *Money in Mesopotamia* (1996): https://www.jstor.org/stable/3632646  
   - Schmandt-Besserat, *From Accounting to Writing*: https://sites.utexas.edu/dsb/tokens/from-accounting-to-writing/  
   - Smithsonian 国家历史博物馆：https://www.americanhistory.si.edu/explore/exhibitions/value-money/online/origins-money
4. **行政分工与领土扩张可能互相促进**：Spencer (2010) 比较六个早期国家形成地区，提出地域控制扩大和专门行政出现相互加强的解释；它是一种可检验模型，**不是国家形成唯一原因或游戏硬门槛**。  
   - https://pmc.ncbi.nlm.nih.gov/articles/PMC2867764/
5. **战争和制度学习可双向作用**：战争不仅有军事胜负，也可能带来迁徙、信息和组织经验交流；战争不能被设成国家形成必需条件。  
   - Grynaviski & Steinsson (2023): https://www.cambridge.org/core/journals/international-organization/article/wisdom-is-welcome-wherever-it-comes-from-war-diffusion-and-state-formation-in-scandinavia/9BDB1A19D1D9FCFDE62C23EC1327AFA9
6. **财富不平等的考古衡量有偏差**：Fochesato & Bowles (2026) 专门处理相关证据的不确定性和测量偏差；不能拿基尼系数自动证明存在统治阶级。  
   - https://doi.org/10.1073/pnas.2514309123

**术语说明**：本设计的“阶级”是生产资源控制、持续依赖与剩余汲取等关系的分析标签；“国家”是组织能力诊断；二者都有理论争议，诊断结果必须保留判定依据而不是伪装历史真理。

## 2. 统一 D01–D12 阶段卡（L1）

| 维度 | S2 研究结论 | Minecraft 可验证对象/事件 |
|---|---|---|
| D01 生态历史 | 可储藏资源、地理集中与运输成本影响征收能力，但不决定制度 | `ProductionLocation`、运输路线、储藏时长 |
| D02 技术生产力 | 农业、加工、测量、记账、建筑和后勤可并存；技术不等于政治 | 真实工具/工坊、仓储、记账行为 |
| D03 劳动组织 | 自主、协作、约定、劳役、债务限制等有不同退出条件 | `LaborObligation`、工时预约与执行事实 |
| D04 产权 | 资源使用/收益/管理/转让/继承/排他可由不同主体持有 | `PropertyRightGrant`、权利转移 |
| D05 经济流通 | 礼物互惠、现货易货、实物借贷、账面债务可以并行 | `ExchangeContract`、`DebtClaim`、实际库存批次 |
| D06 人口照料 | 家庭分合、死亡、继承、负债及照料需求改变经济机会 | 多重关系图、继承案件 |
| D07 社会分化 | 财富差异不等于阶级；稳定控制+依赖+持续汲取才体现关系 | 权利集中度、依赖率、汲取记录 |
| D08 政治制度 | 职位、合法性、支持者、执行能力、公共财政和监督可组合 | `Office`、`Institution`、任免/决议 |
| D09 知识信仰 | 社会记忆、契约记录、仪式与规范能影响权威、但不能瞬间全员知晓 | 已有信任/传播机制、书面凭据 |
| D10 物质生活 | 公仓、房屋、作坊、道路、岗哨体现能力但不直接创设统治权 | 蓝图、实际建筑、可用容量 |
| D11 变迁冲突 | 诉求、欠税、分裂、赈济、战争、继承危机与改革可能逆转制度 | 可追溯争议、迁移、反抗和新规则 |
| D12 玩家体验 | 玩家是帮助者、贸易者、参与者，不默认是国家主权者 | 名册事件、居民请求、真实物品与行动 |

## 3. 三条最重要的“物质→行为→关系→制度→反馈”链

### C1：家庭储备和财产继承
局部歉收 + 资源批次分布不同 → 一家求助/租借工具/借粮 → 形成跨家庭债权债务与信任变化 → 制度选择宽限、债务追偿、抵押、公共救济或债务豁免 → 家庭财富与未来生计能力改变。  
**反事实**：公共救济、替代耕地、亲属网络、迁移与债务取消可以阻止依赖固化。不能规定“借粮三次自动成为奴隶”。

### C2：公共工程和长期征收
公共基础设施真实损坏 → 家庭讨论修缮、招募/承诺工时与物资 → 出现组织者和持续义务 → 集体监督 / 世袭职位 / 强制征收不同规则竞争 → 设施生产力、信任、拒缴和离开选择反过来影响制度。  
**反事实**：公共组织可以保持问责，不必变成统治集团；世袭首领可以拥有支持却未掌控所有财产。

### C3：跨聚落控制和专门行政
远方聚落请求庇护、贸易或遭遇威胁 → 交换、联盟、保护性征收或武力冲突 → 出现定期往来/从属关系 → 外派专员、专门账本、稳定征收或撤销驻守 → 维护成本与反抗、财政收入共同影响控制范围。  
**反事实**：小共同体可以组成联盟而不形成国家；征服后长期占领也可能失败。

## 4. 家庭、继承和财产（D04/D06/D07）

### 4.1 五张必须分离的关系网
- `KinshipLink`：生物双亲、子女及其他**有证据的**社会亲属；旧存档未知者维持 UNKNOWN。
- `ResidenceLink`：谁共享房屋/火塘；搬迁不删除亲属事实。
- `CareLink`：实际照料的当日工时与对象；非亲属也可照料。
- `ProvisioningLink`：谁共同生产、共食和分配资源。
- `PropertyRightGrant`：谁能占有、使用、管理、取得收益、排除、转让或继承具体资产。

原则：死亡、搬家、婚姻、收养、分家**分别是不同事件**。绝不通过改变家庭 ID 自动复制、清空或合并粮食批次。现有 S0 `Household` 和真实双亲映射优先复用，不创建平行家庭账本。

### 4.2 建议权益记录
```text
PropertyRightGrant {
  rightId, assetId, holderSubjectId,
  rightType: USE | ACCESS | BENEFIT | MANAGE | EXCLUDE | TRANSFER | INHERIT,
  scope, shareBasisPoints?, validFromDay, validUntilDay?,
  grantingRuleId, sourceEventId, contested
}
```
- 权益主体：个人/共同供养家庭/亲属集团/共同体/机构/政体；主体 ID 稳定。
- `shareBasisPoints` 只适用于可量化收益份额，0–10000；总和与各权益类型的可分割规则分别校验。
- 物理拥有/物品位置由现有 `ResourceBatch` 和 `StorageOwner`/实际容器决定；权益不是第二份真实库存。
- 同一资产可有多项权利，禁止将“管理员”视为资产唯一所有者；S1 `FieldRights` 将来应复用同一语义，不直接重写 S1 田地模块。

### 4.3 继承状态机（非只有血缘继承）
```text
ALIVE
  --死亡事件--> ESTATE_OPEN（暂停可继承权益的主动转让）
  --按本地规则生成候选--> CLAIMS_COLLECTED
  --无人争议--> ADJUDICATED
  --有争议--> DISPUTED --协商/裁决--> ADJUDICATED
  --批量权益过户--> CLOSED
```
政策初版：`RETURN_TO_COMMUNITY`（公共权利结束/回归），`EQUAL_SPLIT`（合格受益人均分），`DESIGNATED_SUCCESSOR`（指定继承人），`OFFICE_RESELECTION`（职位重新遴选）。不预设父系长子继承；未成年继承人可取得收益权而管理权暂由监护机构行使。

实际库存若需转移，必须由独立的已验证物品转移事件完成；产权变更并不瞬移箱子或新增粮食。冲突/无人继承/资源不足都进入可观察待处理状态。

### 4.4 S2 继承最小对照
同样两个家庭、同样总资产、同样初始饥饿：
- R1 资产按多人均分。
- R2 仅由指定继承人延续。
- R3 核心生产资源归共同体重新分配。
观察 4 期后的资产控制集中度、家庭生计风险、欠债和迁移，而非硬编码哪个制度更先进。

## 5. 易货、信用与货币（D05）

### 5.1 六种交易不能合并
`GIFT` 无即时对价；`RECIPROCITY` 长期互惠预期；`BARTER` 双方即时实物交换；`LOAN_IN_KIND` 真实物资借出并生成债权；`SALE_ON_CREDIT` 先交货后履约；`TAX/TRIBUTE` 制度性非对价义务。礼物可能形成声望或互惠预期，但**不是默认生成可强制执行的债务**。

### 5.2 可执行的债权对象
```text
DebtClaim {
  claimId, creditorSubjectId, debtorSubjectId,
  obligationUnit: RESOURCE_KIND | ACCOUNT_UNIT,
  resourceType?, originalQuantity, remainingQuantity,
  createdDay, dueDay?, interestPolicyId?,
  collateralRightIds[], enforcementPolicyId,
  originTransferEventIds[], repaymentEventIds[],
  status: OPEN | PARTIALLY_PAID | OVERDUE | DISPUTED | SETTLED | FORGIVEN
}
```
- 建债必须有来源：真实借粮已转移，或可核查的延期商品/服务交付；绝不通过新建 `DebtClaim` 同时凭空制造粮食。
- “货币”分为 **计价单位**、**支付媒介**、**财富储藏** 三种能力；从可选的抽象账面计价开始，不要求铸币或统一现钞。
- 先以同类实物偿还，不实现复杂跨商品换算；后来通过当地可观察交易形成报价，不能默认全世界实时统一价格。
- 部分偿还减少未清偿数量，`remainingQuantity >= 0`；过期仅产生争议/催收决策，不自动剥夺土地或人身自由。
- 清偿、宽限、豁免、损失核销与抵押执行均生成新的事实事件。
- 现有跨营地一对一易货继续有效，不从远方仓库隐形取物；交易者只用已知路线、时效性报告和实际货物。

### 5.3 NPC 信用决策
借入选择先检验：生计缺口、现有可用粮、替代来源、关系可信度、期限内预计供给、偿还风险、当地规范和退出/迁移可能。债权人考虑自身剩余、预期偿还、信任、援助偏好、既有关系及执行成本。拒贷是正常结局；玩家不得凭“帮助过聚落”自动获得无限贷款或征税权。

## 6. 政治机构与阶级分化（D07/D08）

### 6.1 职位与人的拆分
```text
Institution { id, polityId?, rules[], treasurySubjectId?, officeIds[], active }
Office { officeId, institutionId, duty, holderPersonId?,
         selectionRule, termEndDay?, successionRule,
         allowedActions[], recallRule, vacant }
CoalitionSupport { supporterSubjectId, officeOrProposalId,
                   stance, knownEvidenceEventIds[], updatedDay }
```
已有 S0 首领是**权力有限的协调者**，不得因为建立 `Office` 就暗中赋予其征收/监禁/产权转移权。职位权限通过已生效规范授权；紧急越权可以发生，却标记为未经授权的行为与争议。

### 6.2 谁支持谁，不使用万能“忠诚度”
对每名知情成年 NPC，针对**具体政策**计算主观净收益，而非统一党派标签：
```text
proposalValue = expectedFoodBenefit + expectedPublicGoods
              + trustInSponsors + normCompatibility
              - expectedContribution - workTimeCost
              - riskCost - expectedRightsLoss
```
权重按人格、经历和当前生计调整，信息只沿 S0 已有关系网络传播。民意/合法性由真实政策兑现、公共账目、损失、支持群体与监督共同更新。权力来源可并存：选举授权、声望、传统、资源控制、官员组织、武力。强制能力与合法性不能互相替代。

### 6.3 不平等和阶级是不同输出
- 计算 `wealthDistribution`：排除由管理员代管的共有资产，避免把公仓算成管理员个人财产。
- 计算 `productiveAssetControl`：生产资源收益与决策权控制度。
- 计算 `livelihoodDependency`：在可用替代生计不足的情况下，有多少家庭长期依赖其他主体。
- 计算 `persistentSurplusExtraction`：连续 3 个**可配置**经济周期内，是否存在重复汲取他人产出的关系。
- `classConsolidation` 是上述关系长期稳定、受规则保护时的诊断，并保存证据事件；不是 `Gini > 0.5`，也不是“职业=农民”。

**政策竞争**：同一事件可导致提高公共储备、调整债务宽限、设置上缴、撤销官员、转向强制执行、允许退出或分裂。每条政策都须改变可读规则/实际权益，而非只变 UI 名称。

## 7. 跨聚落联盟、战争与国家形成（D08/D11）

### 7.1 政治关系状态（允许转向和并存）
`INDEPENDENT`、`TRADE_PARTNER`、`DEFENSE_ALLY`、`TRIBUTARY`、`ADMINISTERED`、`HOSTILE`；战争状态与经济关系应分轴保存，不能简单把所有关系压成一个枚举。跨聚落可存在贸易且政治敌对。关系建立需要有发起者、已知联系人/路线、传达、接受/拒绝及实际履约事件。

### 7.2 冲突并非抽奖
```text
争议：资源/路径/违约/安全威胁
 → 各方获得有来源、可过期的信息
 → 选择交易、补偿、联盟、威胁、袭扰、战斗、迁移或让步
 → 行动投入真实人员、装备、食物和时间
 → 伤亡、物资损失、俘虏、迁出、协约等实际后果
 → 新的谈判与制度变化
```
- 第一阶段只研究外交、贡赋和冲突事件；实体战斗、伤亡、俘虏与实际占领**不随本文件自动启用**。
- 未来战争必须由已加载世界的真实实体行为产生伤亡/损失；在卸载区块不造“幽灵军队”，不凭抽象兵力瞬间写入真实物资。
- 若未来实现俘虏/奴役：独立建 `PersonalStatus`、`LaborObligation`、释放/逃离/争议条件；**不能将人口当 `ResourceBatch`**，也不预设一场战争必须有奴隶。
- 联盟可以长期存在而不变国家；占领可以迅速失效。迁出、退出和反抗与现有 S0 社会选择联动。

### 7.3 早期国家是诊断而不是解锁开关
三项必要事实：
1. **持续地域管辖**：对多个家庭/地区有效的、非一次性的规则。
2. **专门化行政**：有分工明确的常设职位，人员更替后规则仍被执行。
3. **持续征收与执行**：在合法性/强制能力、实际人力和路线允许下，能反复完成财政、裁决或公共工程。
建议辅助指标：跨聚落覆盖、征收成功率、有效行政工时、公共服务、行政成本、投诉/退出、派驻者拒命概率。均由事件观察计算；不存在“人口>20”或“修宫殿即国家”。

行政扩张的反馈：距中心越远，信息延迟/交通/监督成本越高；委派官员减少协调成本却带来滥权和分裂风险。保留独立共同体、高自治联盟、等级酋邦、早期国家和瓦解后的再自治等结果。

## 8. 玩家 5–30 分钟最小闭环：公共仓库的四份马铃薯

**为什么先做此例**：当前 `MinecraftStockpileAdapter` 已覆盖 `POTATO ↔ TUBERS`，且有真实公仓、家庭、饥饿、拒绝、协商、事件账本和易货。无需等待新作物、铸币、军队或宫殿即可验证 S2 的核心制度差异。**这只是技术测试食物，并非说古代两河流域种植马铃薯。**

场景：两户 H-A / H-B、一个公仓、至少两名有社会知情的成年人；A 有合法可用实物马铃薯 8 份，B 饥饿且储备不足；初始资源通过现有测试预置进入唯一权威账本。

| 时段 | NPC自治 | 玩家可见/可做 | 真正的状态变化 |
|---|---|---|---|
| 0–5分 | B 判断生计缺口，向 A 请求 4 份粮 | 与 NPC 交流，提供自己的真实物资或观察 | `REQUESTED`，无库存自动变化 |
| 5–10分 | A 可援助/赠与/借出/拒绝 | 玩家可劝说或提出公共仓救济（若有资格） | 真实转移 4 份，或明确拒绝；借贷另建债权 |
| 10–20分 | B 进食、工作或继续找替代来源 | 看见借条/公仓账目/为何欠粮 | 物资真实消费和工作时间变化 |
| 20–30分 | 到期偿还、部分偿还、申请宽限或催收 | 帮忙归还真实物资、支持协商/豁免或不介入 | `PARTIALLY_PAID`、`OVERDUE`、`FORGIVEN` 等事件 |

**演示加速**：测试场景可预置“距离到期 1 个经济日”并使用受控社会日推进；正常 Minecraft 不保证 30 分钟自然出现完整长期债务危机。测试预置条件必须明确标识，不能把初始粮凭空发给 NPC 但隐藏。

**价值分歧**：同一缺粮事件在不同规范下，可能是无条件救济、互惠赠粮、短期借贷或无援助。即便债务未还，也不自动形成阶级、卖地或奴役。玩家帮忙不是获得聚落财产权的捷径。

**首版 UI**：复用钟名册“概况/事件/居民”页，新增可阅读的 ①缺粮原因，②本次请求与转移，③债权余额/到期，④争议/宽限理由；不新增宏大国策窗口。

## 9. 工程兼容与持久化

### 9.1 当前证据范围
仓库 `README.md`、`docs/civilization-design.md`、`AGENTS.md` 和研究 Issue #25/#28/#32/#35 已核对；存在 `civilization.simulation`、`ResourceBatch`、`StorageOwner`、`NormSystem`、`SettlementSavedData`、`MinecraftStockpileAdapter`、`SettlementForaging`、`LaborAllocator`、`VillagerWorkGoal`、`ConstructionSystem`。**这里提出的 S2 类名是概念接口，不能宣称已有对应代码。**实际修改前以最新源码为准，先找已有事件、持久化及规则接口，避免另一套账本。

### 9.2 事件类型与事务
新增事件示意：`RIGHT_GRANTED`/`RIGHT_REVOKED`/`ESTATE_OPENED`/`INHERITANCE_SETTLED`/`LOAN_ISSUED`/`DEBT_PARTIALLY_REPAID`/`DEBT_FORGIVEN`/`OFFICE_APPOINTED`/`OFFICE_RECALLED`/`LEVY_ASSESSED`/`LEVY_PAID`/`POLITY_AGREEMENT`。每条带 `eventId`、`causedBy[]`、`actorId`、`subjectIds[]`、`day`。只在真实行为成功后提交物资事实；失败记录拒绝/阻塞，不产生转移。

**转移事务：**
1. 校验授权及当前权利；读取唯一权威库存的批次可用量和预留。
2. 以事务 ID 锁定来源批次/现实容器；按已有交接协议执行一次实际转移。
3. 记录来源与去向的事件链接，产生/减少债权或执行义务。
4. 异常/卸载/满仓时释放预留或等待恢复，不能半结算并在重试时再扣一次。
5. 同一事务 ID 重试返回原结果；重载后不重复放粮、不重复继承。

### 9.3 存档迁移和客户端
- `SettlementSavedData` 数据版本按实施时**源码最新值**升级，不按本文记录猜一个整数。旧世界不推测亲属、不生成债权、不擅自改变公仓产权；新功能默认开关关闭或空集合。
- `rightId`、`claimId`、`officeId`、`eventId` 保持稳定；退出家庭/聚落不重用 UUID。
- 服务器唯一权威；客户端只读快照；UI 不允许直接上报“债务已还/官员已被罢免/征税已完成”。
- 未加载聚落仅保留权利、到期和待处理状态，不做无限离线虚拟采集/真实战斗/实际扣仓；上线后依真实库存与旧状态继续。
- 与 S1 的 `FarmPlot` 权利结构通过权益引用对接；与现有规范协商用一套生效规则，不建平行“议会”决策器。

### 9.4 性能预算
事件驱动增量更新 + 聚落错峰；每日只评估到期债务、继承案件和本地议事；社会分层指标按经济周期统计。仅受影响 `subjectId` 进入工作队列。预算采用可配置每 tick 处理数量，**不得每 tick 做所有村民×所有权利×所有仓库的全量笛卡尔扫描**。实际指标记录：耗时、事件队列长度、NBT 体积、同步流量和玩家帧时间/服务器 TPS；与[卡顿排查 #23](https://github.com/ThySummer14/coopcraft/issues/23)关联。

## 10. L2 实验矩阵：3 对照 + 2 边界

所有实验用固定种子、相同初始资源、完整来源账本。以下数值为**测试输入**，不代表古代制度频率。

| ID | 对照变量 | 预期可观察差异 | 不允许预设结果 |
|---|---|---|---|
| EXP-S2-A | 同样两户借 4 份粮：赠与 / 无息贷 / 公共救济 | 库存一样按事实变化，债权及信任/协商事件不同 | 借贷一定造成阶级 |
| EXP-S2-B | 家庭死亡后：均分 / 指定继承 / 资源回共同体 | 权益集中度、使用资格、争议、真实库存一致 | 长子继承必然 |
| EXP-S2-C | 同公共工程：可罢免管理员 / 不可罢免世袭协调者 | 权限变动、劳动招募、盈余分配、投诉记录不同 | 世袭一定失败或更有效 |
| EXP-S2-X1 | 重复回调、服务器两次重载、满仓、部分还款 | 同一实际资源仅转移一次；债务余额不负、不重置 | 用 UI 数量代替实物 |
| EXP-S2-X2 | 家庭迁离/成员死亡/区块卸载/联系过期 | 不瞬移、不读远方实时库存、债权状态可恢复 | 离线自动战争与纳税 |

补充长期实验（非首版门槛）：20/100/500 个**抽象居民**；3×1000 个经济日，比较制度稳态、资产集中、进出家庭、行政负担与事件保留量。不得把抽象居民性能误写成 500 个加载村民实体都不卡顿。

### 必须始终通过的属性测试
- 物资只有生产/合法导入后增加，真实消费/腐败/合法导出后减少；一笔转移本身不创造物资。
- 债权不等于食品库存；部分偿还不复制批次，余额在 `[0, 原债务+合法费用]` 内。
- 任命/罢免不修改公仓所有权，职位空缺期间不会以旧权限自动征收。
- 不存在权利的村民仍可参与交易、表达拒绝、寻求迁移；不会被新模型强制赋身份。
- 相同 seed + 初始状态 + 已知事件次序得到同样输出；事件包含引发规则改变的原因。
- 关 S2 开关/加载旧存档：S0 现有公共仓、分享规范、易货和真实工作不回归。

## 11. 工程切片、依赖与冻结条件

| 次序 | 提交粒度 | 必须做 | 通过条件 |
|---|---|---|---|
| P0-A | **S2研究及接口对照** | 本文归档，审查最新类/存档/测试，列出映射，不写行为 | 明确已实现/未实现，避免重复 |
| P0-B | **家户实物借贷** | 在 S0 既有批次转移上增加 `DebtClaim`，实物借出/部分偿还/宽限/豁免 | JUnit 固定种子、两次NBT重载、物资不复制 |
| P0-C | **一场可见的债务协商** | 复用 `NormSystem` 与名册，NPC 自主请求与拒绝，玩家可贡献真实物品 | 5–30分钟体验 + GameTest，关闭开关不影响 S0 |
| P1-A | **继承与权益** | 先实现有限资产权利、继承案件与争议；不强迫 S1 已在施工的农地重构 | 多继承人和社区回收规则验证 |
| P1-B | **职务与征收** | 分离职务/人，公共财政、制度性定期义务，真实可支付/欠缴 | 可罢免且职位权力不转化私人所有 |
| P2-A | **跨聚落协议** | 已知路线、联盟/贡赋关系、行政委派与信息延迟 | 不读远方实时库存、不隐藏扩张成本 |
| P2-B | **战争、俘虏和奴役** | 待完整行动、身份、人身权利与军事成本系统评审后拆分实现 | 无凭空军队/物资/奴役标签 |
| P2-C | **国家状态诊断** | 从稳定治理事实得出分类，支持衰退/分裂/重组 | 无人口/建筑/时代直接跳变 |

**冻结 v0.1 的条件**：L1 12维、3条因果链、文献与争议、1个可玩闭环、3个对照和2个边界实验均具备（本文件已形成规格）；但 **L2 完成须等 P0-B/P0-C 真实实现、JUnit、GameTest、玩家试跑全部验收**。研究设计完成 ≠ 已开发。

## 12. 下一步研究队列（不阻塞首版）
1. 劳役义务、人身限制、债务依附与奴役之间的不同法律/行动边界，必须避免“债务→奴役”无条件转换。

4. 跨聚落和平联盟的行政形式，与战争征服对照。
5. 将 S2 文档链接并入研究文库导航（在 PR #24 合并或协调后，避免当前两条分支修改同一 README 冲突）。

**验收哲学**：不是在1000天内必须出现国家，而是当社会出现征粮、债务、继承、行政和政治竞争时，任何结果都能从行为、权益、工时和真实物资事件中追溯；不存在“时代升级令一切关系瞬间变样”的脚本。
