# 交给开发 Agent 的执行说明｜原始社会 v1.0

请将同目录的《文明演化Mod_原始社会完整设计与Agent交接_v1.0.md》作为**本阶段最新设计基准**，并与旧文档 `primitive_society_economy_design_v0.1.md` 对照阅读。

## 任务定位

我们的目标是 Minecraft 原始社会文明模拟。不是固定时代解锁树。社会制度要从居民的生产、分配、资源控制、互助、知识、家庭与冲突行为中涌现。当前只做原始社会，暂不扩展奴隶社会等后续文明阶段。

## 你必须先做的事情

1. **先审计当前仓库**：确认游戏版本、Mod Loader、Java 版本、工程结构、现有提交及已经实现的模块。不要因为新文档就删除或重新写掉已完成的工作。
2. **输出差距表**：按照主规格的 P0/P1/P2/P3 逐项标注「已实现、部分实现、未实现、冲突、需验证」，并列出受影响文件。
3. **先贯通 P0 纵向切片**：居民缺粮 → 知晓资源 → 实际采集或捕鱼 → 资源扣减和产品生成 → 搬运/野外消费 → 请求分享 → 接受或拒绝 → 关系与记忆变化 → 事件历史与存档。
4. **核心与 Minecraft 分离**：能独立、确定性地用随机种子运行社会引擎，并在 Minecraft 中以实体和方块表现结果；近景和后台人口不重复结算。
5. **功能必须可验证**：优先做守恒、时间冲突、信息有限性、独立权利束、存档重载和行为闭环自动测试。

## 不允许的捷径

- 不能按固定年份或资源数值自动切换私有制、阶级、国家或时代。
- 不能让 NPC 全知、全部科技瞬时共享，或令职业天生固定。
- 不能用一个 `ownerId` 或一个好感度数值替代完整社会关系。
- 不能让物资在未加载区块与可见实体之间复制或遗失。
- 不能把所有事件写成随机剧情文本，不发生实际世界状态变化。

```text
本轮完成：

未实现项与风险：

```

请从**检查已有工程和输出差距表**开始，而不是直接重构。若有设计冲突，以实际已实现功能、可测试性与主规格目标共同评估，明确理由后再修改。
