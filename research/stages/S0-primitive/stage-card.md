# S0｜流动采集与早期共同体：阶段卡 v1.0

- 当前状态：**L2研究设计 v1.0 已覆盖并确定开发边界；软件未通过本轮实机验收，不能声明S0已经完工。**
- 工程：Fabric / Minecraft 1.21.1 / CoopCraft。
- 来源：[研究框架 v1.1](research-framework-v1.1.md)；[原始完整理论设计 v1.0（归档）](archives/full-design-v1.0.md)；[玩家参与方案](player-participation-v0.1.md)。
- 研究性质：涵盖多种早期社会生计与组织方式的设计单元，不是所有史前社会的统一复原。

## 三条核心因果链

1. 资源季节性及风险 → 居民采集与移动 → 食物运输、分享与储备 → 形成/改变共同体规则。
2. 分工、技能、知识传播 → 生产能力差异 → 合作与社会关系变化 → 权威与制度实践。
3. 设施投入和可控制资源 → 产权主张及协商 → 出现不同资源使用安排 → 群体维持、迁徙、分裂或权力分化。

## 最小玩家闭环

**发现在营地发生的资源短缺 → 了解一名居民的真实困难 → 用材料或劳动参与 → 村民自主回应 → 物资/关系/规则发生真实变化 → 玩家下次归来能看到后果。**

## L2研究结论与软件封版的区别

**研究封版**：D01–D12已有因果、玩法、来源、实验和工程边界。**软件封版**：必须通过综合设计中的P0/P1实装与Gradle/GameTest/真实客户端/两人联机验收。新研究专题不再自动扩张S0范围。

## L2软件封版所需

- NPC 无玩家指令仍能生产、消费、合作，且经济和物资批次守恒。
- 玩家至少有两种不同的、具有实际社会后果的参与策略。
- 至少一项社会规范在 Minecraft 真实库存中生效，并可修订。
- 研究给出3组对照和2组边界实验，含失败与资源不足。
- 现有模组核心、存档、联机和 GameTest 不因新增研究退化。

- 社会权利、家户和住房制度演化的长期行为效果。
- 生计与聚落空间表现在不影响性能的前提下如何逐步丰富。
