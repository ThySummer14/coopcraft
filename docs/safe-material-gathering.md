# 明确许可内自主采集木石

村民可以从已有观察候选中选择本营明确许可区内的普通橡木原木、石头或圆石，不必逐块人工标记。候选来源仍是UNKNOWN，不根据树叶、地形或建筑距离猜测天然来源；实际采收由区域许可和当前执行条件共同决定。

## 设置范围

1. 先用 `/coop protect` 保护不愿拆除的房屋、庭院、地基和支撑。
2. 站在允许采收区域中心，执行 `/coop settlement gathering preview wood 4`。模式可选 `wood`、`stone`、`both`，半径1至8。
3. 核对聚落、维度、材料模式及固定范围后，用 `/coop settlement gathering confirm` 确认；`cancel` 放弃。
4. `/coop settlement gathering` 查看当前许可，`revoke` 撤销。修改需要OP2，查看允许普通存活非旁观玩家。

范围是包含边界的全高度X/Z正方形，边长为 `2 × 半径 + 1`，包括地下、屋顶及当前和以后由玩家放置的同类方块。**不要把自己的建筑放在许可区内而又遗漏保护。** WOOD仅普通橡木原木，不含其他树种、去皮木或木板；STONE仅普通石头和圆石，不含矿石、深板岩、石砖或其他岩石。BOTH是两者合集。

每营一个许可区，每维最多128区；四角均须在营中心水平64格内和世界边界内。不扫描范围、不宣称土地所有权，联机时请先协商。预览绑定实际玩家实体、维度、聚落、中心、模式、旧许可和固定截止时间，最多256份，五分钟失效；重复预览不延长同一会话。换维、离线、重生、营地或许可变化后需重新预览。命令不接受控制台或伪装的执行维度。

## 从发现到采收

实际发现仍使用原观察器，每维每tick最多16个坐标；木石与浆果、抑制记录共享每营64条候选上限。自动选择只遍历这个有限列表，先校验本营许可、保护、材料类型和12格作业距离，再读取当前已加载、entity-ticking且在世界边界内的方块。历史候选不是当前方块或路径证明，不会为许可区新增广域扫描或强加载。

已有人工标记在相同材料类别内优先，原建造原木、职业、木棍/圆石需要及工具兜底顺序保留。没有候选不代表区域采空：满额、远离居民、未活动区块、抑制、路径、角色及工作优先级均可能使其暂不采集。许可不保证自动探索整片区域、采完树冠或开凿矿道。

观察仍不赋予权限。自动木石任务额外要求同一个未抑制候选继续存在；`observations suppress <ID>` 会停止该点的自动木石任务，`resume` 清除抑制后须重新观察。它不撤销区域许可，不影响原人工标记和甜浆果路径，也不是跨聚落禁采区。永久保护建筑应使用保护区，停止本营全部自动材料采收应撤销gathering许可。

## 取消、保护与实物

新任务绑定原许可、成员、候选和当前方块。选择、继续、逐tick、导航及实际破坏前重验；撤销、更换、撤销后重授、退籍后重加、候选变化、保护新增或世界状态变化不能让旧任务继续。保护区始终优先，包括保护数据损坏。已完成的实际采收不倒退，不凭撤销复制退款或回收物品。

普通Goal的手动和自动材料任务共用有限坐标预约，防止同时持有同一目标；每居民最多一张、每维最多128张，固定2400tick到期，不反复续期。停止、失败和完成释放，重启不恢复。预约只协调工作，不授予土地或材料权利，不保证公平派工。

旧的直接手动采收适配器没有纳入预约，仍执行其原有实时标记、方块与保护检查；预约不保证其他调用者或模组的独占行为。时钟倒退会使旧预约失效，再按新的有效时刻领取，不恢复旧任务。

自动路径使用真实掉落的副本，先检查全部输出能否放进背包，再执行一次成功的世界破坏，最后提交实物。合计容量不足或世界修改失败时，不破坏、不产出、不记练习；不会按候选类型凭空生成原木或圆石，不新增同份抽象库存。原人工采集保留既有逐栈检查及溢出落地规则。普通服务器线程、非重入容器的事务边界不等于跨文件崩溃原子性或任意第三方回调保证。

保护仍只拦截文档列出的CoopCraft直接行为，不阻止邻接更新、落沙、流体、树叶凋落、原版村民或其他模组。单块采集可能影响支撑和周围环境，应把需保留的支撑与缓冲一起保护；本轮没有自动判定地形稳定性、重种树苗或生态恢复。
