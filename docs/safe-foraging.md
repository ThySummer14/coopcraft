# 安全自主采浆果

村民可以在玩家明确授权的范围内自行寻找成熟甜浆果，无需逐丛标记。授权只允许采摘甜浆果，将灌木年龄退到1；不会授权砍树、挖石、改农田或自动建造。观察记录仍是 UNKNOWN，不把方块外观或“保护区以外”当作天然来源。

## 设置一次范围

1. 站在拟授权范围中心，且位于目标聚落64格内。
2. 用 `/coop settlement foraging preview 8` 预览以当前位置为中心、半径8的区域。半径可选1至16。
3. 核对聚落、坐标及范围，再执行 `/coop settlement foraging confirm`。用 `cancel` 放弃预览。
4. `/coop settlement foraging` 查看当前许可，`revoke` 撤销。已有 `/coop settlement status` 也会显示许可是否配置及暂停原因。

查看允许普通玩家；预览、确认、取消和撤销需要OP2。管理权限不代表确认了土地归属，联机时应先与其他玩家协商。命令使用玩家实际维度及附近聚落，不接受控制台或通过执行上下文替换真实维度。

范围是包含边界的正方形，边长为 `2 × 半径 + 1`，覆盖整个建造高度，包括地下与屋顶。许可包括区内现有和以后出现的成熟甜浆果，**也包括玩家种植的灌木**。请只圈愿意供本营采摘的区域，把不愿采摘的建筑、庭院和农场设为保护区。四角均须位于聚落中心水平64格内及世界边界内。每营一个区，每维最多128区；更换范围后旧许可失效。

预览固定聚落、实际维度、坐标、半径及当时的旧许可，不因为确认时移动就悄悄改变授权。预览五分钟过期，最多256份；离线、换维、重生和服务器关闭使其失效。他人更改许可后旧预览不能覆盖新范围。没有扫描或加载整个区域。

## 保护和撤销

保护区是优先否决层，重叠部分不能采摘；保护数据未知或损坏时也不能采摘。删除保护区只解除否决，不会额外生成采集许可。不同营地各需自己的许可，不能借用邻营范围。

选择目标、途中继续、计算掉落后和实际降低成熟年龄前都会重新检查。撤销或更换许可、成员失效、目标变成其他方块、未成熟、区块不再活动或新增保护时暂停；旧任务不能借同位置重授权复活。已经产生的实际货物保留，继续按原有保龄和返仓规则处理，不重复发放或回滚。

同维度的浆果目标最多128张互斥预约，期限为200游戏tick；每位居民最多一张，不能反复续期。停止、成功、失败会释放，未及时清理的预约也会到期，重启不恢复。预约不创造物品、不代表持久土地所有权，也不保证公平派工。

## 发现与范围边界

本轮使用已有居民附近有限实时搜索，在本人所在聚落的许可范围内寻找当前成熟浆果，读取前检查高度、世界边界、已加载与entity-ticking；不会为整片授权区派出远程扫描或开荒。原搜索距离仍为居民水平12格、上下4格，许可区没有扩大寻路或采收距离。

持久观察与实时目标分开：64条历史候选满额不会使有效许可自动失效，旧候选也不能代替现场复核。`observations suppress` 不影响本节的浆果采摘，不能代替保护区或撤销许可；新木石自动路径依赖未抑制候选，具体见安全木石采集说明。

途经邻格及上下方必须满足加载和活动检查，觅食路径复用已有保守加载范围及节点检查。不声称第三方寻路实现、所有邻接更新或整个世界绝不会加载区块。保护区仍只约束文档列出的CoopCraft直接生产与施工，不阻止原版农民、踩踏、玩家、机器或其他模组。

## 升级和存档

**旧存档没有许可时，原本无区域限制的自动浆果采摘将暂停。** 即使饥饿也不绕过。请先配置允许采摘的范围，或继续供应已有公仓食物、使用人工标记的土豆田。不会补发食物、重置饥饿或改动旧库存；已有背包货物照常保留。人工木石和土豆标记不因此停用或扩大。

甜浆果许可在根存档版本22引入（当前根版本23），`ForagingAreas` 子树仍为版本1。缺字段就是没有许可，不从旧观察、资源标记、保护区或地形推测授权。未知/损坏子树整块原样保留并拒绝采收及编辑；重复聚落/许可ID、坏类型、坐标/半径非法或超限等都不部分加载。已保存合法范围若不再符合当前营中心64格限制，该许可也暂停，查询会明确提示，可由玩家重新预览正确范围。许可只对当前可确认的本营生效，孤儿或含混营地记录不授权。瞬时预览和预约不存盘。升级前备份整个世界，避免旧版回写新数据。

## 验证边界

针对许可、预览、撤销、库存守恒及预约补充自动回归源码，并只作必要静态检查。编译和JUnit结果见开发记录及首次CI；没有启动Minecraft客户端、服务器或GameTest。实际导航、多居民竞争、第三方模组和真实世界重启待用户统一测试。
