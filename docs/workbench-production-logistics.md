# 木板工作台生产：真实领料、操作与返仓

第七十一增量只接通已有登记工作台的橡木板配方。公仓领取一根普通橡木原木，村民带到台前，完成原有制作工期后在背包得到四块木板，再实际送回公仓。先前“走到台前，但远程在公仓扣料并直接生成产物”的木板路径已停用。

## 如何使用

- 仍用潜行右击工作台登记制作站，潜行右击箱子或木桶登记公仓，不新增命令或后台工厂。
- 有兼容的现有工程或待建项目缺少木板，或其配方需要木板中间料时，沿原有建材需求选取一批。
- 村民须能够到达仓和台的同高、清空、坚实地面的水平邻格；只在已加载活动区块内寻路，狭窄、封闭或高低错层的站点可能暂时不能操作。
- 名册动作分别显示“前往公仓领取木板制作原料”“在工作台用携带原木制作木板”，完成后走既有“携带货物返回公仓”。只展示正在进行的动作，不代表整条路线已经完成。

## 物品和中断规则

| 阶段 | 实物所在 | 库存变化 |
| --- | --- | --- |
| 领料前 | 公仓，或已启用的旧抽象木材批次 | 只读选择不扣料 |
| 实际领料 | 村民背包中一根带工作台用途的橡木 | 真实公仓减一；抽象来源只在仓边导出，再真实领取 |
| 运到工作台 | 仍是同一带用途原木 | 计时和移动不预生成木板 |
| 完成操作 | 背包四块带产物用途的木板 | 消耗该批输入，不向公仓或抽象库存再加副本 |
| 实际返仓 | 接收数量进入公仓 | 仅已接收部分去除用途标记，余量继续留包 |

一次只领一根，背包已有任何工作台用途货物时不开始新批次；背包必须能先容纳用途原料、之后完整容纳四块产物。玩家命名或有其他组件的原料、施工专用物与旧个人木板不被征用；普通个人木板仍不自动归公。原木与产物使用独立的版本1物品标记，包含来源营地、批次和阶段，不存虚拟物品副本。

途中饥饿、赴会、导航失败、仓绑定或成员变化会终止本次工作；需求或图纸改变也保守停止。已领原料留在真实背包，随后可由来源营地居民实际送回当前公仓。满仓只接收能装下的数量，不能到仓则保留。取消、正常保存重载不恢复旧制作票，也不凭票补发原料或产品。已领走最后一根原木后，台前加工不再要求公仓里还剩第二根。

在本次材料处理路径中，坏格式、未知版本、额外组件或其他营地的标记保持原样，不自动消费、解标记或返仓。死亡遗物沿现有观察到的成员死亡流程保存真实工作台货物与完整组件，包括未知格式；玩家回收不等于自动续做，普通物品转换及第三方行为不受全局拦截。

## 权限、来源与兼容

- 仓边取料与台前完成都检查当下成员、维度、活动实体、登记位置、原仓实体和模式；登记工作台位置变化后改回也不会恢复原票。物理工作台被同种方块替换且两次检查之间不可观察时，没有额外世界历史可据此判定。
- 原仓与工作台必须持续可用，已领材料不因原仓暂时失效而消失。身份和需求检查只撤销工作资格。
- 制作完成事件只关联本次同步领料窗口内的直接原料导出；窗口在出发前封闭，走路期间其他同人同配方导出不会串入。已有真实原料的更早历史来源仍标为未知。
- 根存档版本仍23，不迁移旧工程、库存或成员。新增工作台登记代次和制作票是瞬时状态；新标记随真实物品正常保存，升级前备份世界，不保证旧版本能安全识别新用途。

## 尚未覆盖

首个工作台的仓边徒手启动保持原路径；木棍、工具、其他公共建材和磨制仍有既有远程领料/产出行为，不能把本增量称为全配方实体物流。没有增加工坊多人排队、统一在途库存或批量生产预约；多个居民可能各携一批，公仓缺口也未扣除在途产品。需求变化时采取保守取消退料，可能增加往返。
