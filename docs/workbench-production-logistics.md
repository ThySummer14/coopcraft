# 工作台生产：木板与橡木门的真实往返

第七十一增量接通已有登记工作台的橡木板配方，第七十二增量扩展橡木门。公仓领取一根普通橡木原木，村民带到台前，完成原有制作工期后在背包得到四块木板，再实际送回公仓。橡木门每批领取6块普通橡木板，在台前制成3扇门后返仓。先前这两种配方“走到台前，但远程在公仓扣料并直接生成产物”的路径已停用。

## 如何使用

- 仍用潜行右击工作台登记制作站，潜行右击箱子或木桶登记公仓，不新增命令或后台工厂。
- 有兼容的现有工程或待建项目缺少木板，或其配方需要木板中间料时，沿原有建材需求选取一批；橡木门需求沿当前工程/待建项目的实际门缺口判断。
- 村民须能够到达仓和台的同高、清空、坚实地面的水平邻格；只在已加载活动区块内寻路，狭窄、封闭或高低错层的站点可能暂时不能操作。
- 名册动作分别显示“前往公仓领取木板制作原料”“在工作台用携带原木制作木板”，完成后走既有“携带货物返回公仓”。门配方也显示对应领料和台前制作动作。只展示正在进行的动作，不代表整条路线已经完成。

## 物品和中断规则

| 阶段 | 实物所在 | 库存变化 |
| --- | --- | --- |
| 领料前 | 公仓，或已启用的旧抽象木材批次 | 只读选择不扣料 |
| 实际领料 | 村民背包中一根带工作台用途的橡木 | 真实公仓减一；抽象来源只在仓边导出，再真实领取 |
| 运到工作台 | 仍是同一带用途原木 | 计时和移动不预生成木板 |
| 完成操作 | 背包四块带产物用途的木板 | 消耗该批输入，不向公仓或抽象库存再加副本 |
| 实际返仓 | 接收数量进入公仓 | 仅已接收部分去除用途标记，余量继续留包 |

每次只领一批：木板配方一根原木，门配方六块普通木板。背包已有任何工作台用途货物时不开始新批次；背包必须能先容纳全批用途原料、之后完整容纳全批产物。玩家命名或有其他组件的原料、施工专用物与旧个人木板不被征用；普通个人木板仍不自动归公。原木与木板产物继续使用原版本1标记；门配方使用严格版本2并增加Recipe字段。两者记录来源营地、批次和阶段，不存虚拟物品副本。

途中饥饿、赴会、导航失败、仓绑定或成员变化会终止本次工作；需求或图纸改变也保守停止。已领原料留在真实背包，随后可由来源营地居民实际送回当前公仓。满仓只接收能装下的数量，不能到仓则保留。取消、正常保存重载不恢复旧制作票，也不凭票补发原料或产品。已领走最后一批原料后，台前加工不再要求公仓还剩第二批。

在本次材料处理路径中，坏格式、未知版本、额外组件或其他营地的标记保持原样，不自动消费、解标记或返仓。死亡遗物沿现有观察到的成员死亡流程保存真实工作台货物与完整组件，包括未知格式；玩家回收不等于自动续做，普通物品转换及第三方行为不受全局拦截。

## 权限、来源与兼容

- 仓边取料与台前完成都检查当下成员、维度、活动实体、登记位置、原仓实体和模式；登记工作台位置变化后改回也不会恢复原票。物理工作台被同种方块替换且两次检查之间不可观察时，没有额外世界历史可据此判定。
- 原仓与工作台必须持续可用，已领材料不因原仓暂时失效而消失。身份和需求检查只撤销工作资格。
- 制作完成事件只关联本次同步领料窗口内的直接原料导出；窗口在出发前封闭，走路期间其他同人同配方导出不会串入。已有真实原料的更早历史来源仍标为未知。
- 根存档版本仍23，不迁移旧工程、库存或成员。工作台登记代次和制作票是瞬时状态；标记随真实物品正常保存，原版本1合法木板标记继续可读可返。升级前备份世界，不保证旧版本能安全识别新门用途。

## 尚未覆盖

首个工作台的仓边徒手启动保持原路径；木棍、工具、除木板和橡木门外的公共建材及磨制仍有既有远程领料/产出行为，不能把本增量称为全配方实体物流。没有增加工坊多人排队、统一在途库存或批量生产预约；多个居民可能各携一批，公仓缺口也未扣除在途产品。需求变化时采取保守取消退料，可能增加往返。

标准同步、不可重入容器的守恒和自动回归不等于跨文件崩溃原子性。没有启动Minecraft客户端、服务器或GameTest，实际路径、AI竞争、动画、工作时长和真实世界重启由用户随后统一验收；不声称已经验证手持模型或专用操作动画。


## 橡木门批次的数量边界

6块普通木板可以从公仓多个槽位汇集；只有5块、来源是个人或施工用途木板、包内全批放不下，均不提前扣走一部分。领料后即使公仓木板为0，完整在途6件仍可按当下门需求加工，前提是身份、工程与站点仍有效。

完成后3扇门留在带用途背包，尚不能被当作普通施工门使用。实际返仓时按仓可容纳量解标记；只收1扇时其余2扇仍留包。取消后的输入也可分批退回，部分输入不能再完成合成。返仓得到普通门后，才交给既有单件门安装物流；本轮没有启动世界来验证安装。

未知版本、配方、字段或不匹配物品继续保留隔离，V1不会因V2扩展而接受额外字段；不能靠把旧V1原木换成木板取得门制作资格。玩家自定义木板与门仍不自动征用。木板没有抽象资源映射，因此门配方只接受真实公仓输入，不从数字账本生成木板。
