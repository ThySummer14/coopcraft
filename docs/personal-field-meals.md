# 原地吃随身口粮

默认实物模式的居民，饥饿且背包里已有普通食物时，可以在安全站位停下吃饭，不再必须先到公仓。动作显示“吃随身口粮”。此流程只消费本人背包中的食物，不代取公仓或其他人的粮食，不处理抽象配给。

## 进入与实际消耗

- 开始时聚落饱食不高于35；每口要经过40个连续游戏tick，完成才消费一件实际食物，并沿原公式每食物点恢复5饱食、上限100；一轮可在低于95时继续，整轮最多800tick。
- 普通面包、胡萝卜、马铃薯、甜菜根与甜浆果沿用原村民食物点表及浆果扩展。不是原版所有玩家食物都能给居民吃。
- 新动作只接受没有额外组件补丁的食物。标龄、新旧或未知用途货物、施工材料、剪毛货物、借用标记、命名及其他组件食品不会被这条路径消费。原公仓进食对其他食品的既有语义不在本轮重定义。
- 不移走主副手工具，也不把背包食物临时换到手里。可以在保管待返仓货物或借用剪刀时先吃自己的普通粮食，不清除其用途或归还责任。
- 不要求公仓存在或可达，生存模拟开启时仍走原公仓配给/额度流程。本动作不导入或导出抽象粮，不创建领取、拒绝、制作经验或社会关系事件。

## 中断与边界

成员、实体、模式和现场持续核验。睡眠、交易、惊恐、近期受伤、当前位置失效、卸载或成员变化会停止；开始与每一口均不预扣食物，未完成不能凭等待补吃。模式开关来回切换、保存重载后不能复用旧票或进度。

原本有效的其他劳动不被新动作普遍抢占。已有默认模式到仓进食在拥有合格个人粮时可以改为原地进食，避免公仓路径卡住；原模拟模式的排队、额度与拒绝不变。

此改动不接管原版Brain，也不把原版繁殖食物点与聚落饱食度混为一谈。标准服务器线程、非重入普通背包内的一次交接不等于跨世界保存崩溃原子性或任意第三方容器保证。没有新增存档字段；升级前仍要完整备份世界，不让旧版回写新用途货物。

## 用户实机验收

仅在备份副本执行：准备饥饿、清醒且无当前有效劳动的居民，给其普通食物；分别测试无登记公仓、公仓不可达、公仓空仓，观察原地动作、本人食物减少与聚落饱食增加。不能把仓内食物减少当成个人餐成功。

分别测试只有命名/用途标记粮、途中移动或受伤、模式开关变化、本人粮被其他行为消耗、携带工具及用途货物、正常退出重进。未完成的一口不应扣物或补算，非食物和用途货物应保持；恢复条件后重新选取。
