# 逐羊许可、真实剪毛与返仓

## 已实现的范围

第七十五增量建立逐羊许可，第七十六增量把它接入村民劳动：已有真实主手剪刀的成年成员，在公共白床仍缺羊毛时，寻找本营明确获准的成年白羊、走近操作、把本次实际掉落的羊毛带回公仓。现有4线→1白羊毛→白床运输链仍保留。

首版不自动领剪刀、不换装、不复制手持模型，也不改村民原有手中物品。必须先由玩家或已有游戏机制装备真实剪刀；没有剪刀的居民不会凭空取得工具。剪刀既有组件、附魔和耐久交给原版处理。这不是完整畜牧系统，没有繁殖、染色、喂养、围栏建造或动物迁移。

羊没有可供本模组可靠验证的玩家主人字段。名称、围栏、牵绳、村庄附近或外观不能代表公共所有。由OP2管理员明确选羊，许可仅限指定聚落今后的重复剪毛，不授权杀羊、迁移、染色、繁殖、后代或其他羊，也不是动物所有权证明。

## 授权命令

在目标聚落附近操作：

1. `/coop settlement shearing`：查看本营已保存的许可，不扫描或加载羊。
2. `/coop settlement shearing nearby`：查看真实玩家8格内已加载候选，最多显示8条。显示候选不产生许可。
3. OP2执行 `/coop settlement shearing preview <sheep_uuid>`：选择附近存活成年白羊，核对精确UUID、聚落与用途。已被剪过的白羊可登记今后的重复剪毛许可。
4. `/coop settlement shearing confirm`：有效期内保存。预览单次消费，失败后重新预览。
5. `/coop settlement shearing cancel`：取消自己的未确认预览。
6. `/coop settlement shearing revoke <sheep_uuid>`：撤销本营对应许可。羊已卸载、死亡、走远或进入保护区也可撤销。

只读查询不需要管理员权限，修改同时要求命令源和真实在线、存活、非旁观玩家有OP2权限。使用实际玩家位置和维度，不能用`/execute positioned`远程授权，不接受跨维度执行。每羊在同维度最多一营许可，每营16只、每维度128只。换营先撤销原营，再重新确认。

预览绑定玩家会话、实际维度、聚落/存储/羊实例及许可变化代次。重复预览不延长首次有效会话的6000tick时限，最多256会话；时钟倒退、断线、换维或重生会失效。许可变更或撤销重建不能恢复旧确认。

## 村民如何工作

- 只按当前本营至多16条许可查找已加载实体，不扫描所有动物，不为工作加载区块。选择时羊距村民12格内、营中心水平64格内，仍为存活成年、未剪白羊。
- 目标、村民、许可、成员、模拟模式、仓绑定和原主手剪刀都绑定到当前实例；手中换物、组件变化、许可撤销重建、成员变更、羊重载或保护变化时不能继续旧任务。
- 移动中更新羊的位置并限频重寻路；路径搜索前检查区域加载，路径节点也须已加载、活动且在边界内。超时、受阻或卸载释放占用，不保留跨重载执行票。
- 距离不超过3格且可见才积累操作时间。羊走开则重新靠近，不远程剪毛；最终下剪前再次复验。逐羊短期占用阻止两个村民同时操作同一羊，过期或旧占用不能覆盖新任务。
- 公仓普通白羊毛已够下一张床3份，或床需求已经满足时，不再开始或完成新的剪毛。该规则只检查当下公仓需求，不是全村在途预约：多只羊、编织和返仓并发时仍可能超过3份，所有产物都来自实际投入或真实剪毛，不会删除多出的羊毛来强制配额。

## 真实产物与剪刀

`Sheep.shear(SoundSource)`会置已剪状态，原版循环生成1–3个同色羊毛实体。Mixin只在该方法的精确`Sheep.spawnAtLocation(ItemLike,int)`调用点观察返回对象，不改变原调用次数、返回值或产量；这里的`int`是Y偏移而非物品数量。捕获器限定本次羊实例和首层调用，退出或异常时清理，不凭附近物品差集推测归属。

执行前预演背包可容纳本次最多3份专用货物；收货时仍核对每个真实实体未移除、同世界且`level.getEntity(uuid)`就是该对象。只接管可识别的普通白羊毛，未知组件或异常产物留在世界，不生成替代物。插入成功多少，才从原实体扣多少，空了才移除；剩余仍是原掉落实体。

已剪羊不能因后续满包、失败或异常恢复未剪，也不能再调用一次剪毛补偿。剪毛事件与剪刀耗损由外层各处理一次；真实主手剪刀调用原版`hurtAndBreak(1, villager, MAINHAND)`，附魔、耐久和破损通知不另行重算。

产物带独立`coopcraft_shearing_cargo`版本1标记，记录营、批次、羊和许可身份。标记只说明这批真实货物的来源，不替代新的动物操作许可。实际返仓时才去掉合法用途标记，仓满或部分接收保留剩余原数量；撤销许可不销毁已经产出的货物，也不要求羊还在现场才能返仓。死亡恢复保留实际包内货物，包括无法理解的标记；未知、未来、其他营或异常组件不会被普通生产路径拆作材料。

## 保护与兼容边界

- 预览、确认、选择、行进和执行均检查羊整个包围盒的XZ投影；保护区边缘相交也否决，未知保护数据禁用。已保存许可不会因羊暂时进入保护区而静默删除。
- 根存档仍为24，许可子树Version1不迁移。旧档缺字段无许可；新格式缺字段及坏/未来/重复/超限数据保全并禁用，不自动推导授权。
- 短期任务、占用与捕获作用域不存盘。真实包内货物正常保存，重载后重新安排返仓，不恢复旧剪毛票。
- 保护仅约束本模组直接动作，不拦截玩家、发射器、原版其他生物、其他模组或间接环境变化。用途标记也不是所有原版/第三方配方的全局权限系统。
- 实物转移采用普通服务端同步、非重入容器语义；不保证任意第三方监听器重入、抛异常或篡改实体情况下的事务原子性。多个实体/区块/存档文件之间也没有进程崩溃原子提交。主手已有工具的死亡掉落仍遵循游戏既有装备规则，本步没有新增公共工具托管。
