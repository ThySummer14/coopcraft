# 留粮后的土豆扩种

## 能做什么

居民已有的土豆收获可以成为扩种种源：在默认实物食物模式，背包普通土豆超过原留粮底线时，居民可走到明确许可的现成空耕地旁，停步播种1颗。作物日后自然成熟，继续走原有采收、留1颗复种、搬运余粮的流程。

没有自动锄地、供水、清草、施肥或催熟，也不从公仓远程扣种。只用无组件普通马铃薯，不用毒土豆、命名土豆、带货龄或其他用途的种薯。

## 玩家怎样准备

1. 准备一格现成耕地及适合土豆存活的光照，上方为空气。在旁边留同高、安全的普通全方块走道；首版不以耕地为播种站位，也拒绝路径节点走过耕地。
2. OP2站到作物格6格内，执行 `/coop settlement planting mark <x> <y> <z>`。坐标填作物格，不是下方泥土格。例如耕地在`10 63 0`，命令填`10 64 0`。
3. 用 `/coop settlement planting`查看保存的位置及许可是否仍有效。该查询不扫描空地、种子或路线，不承诺马上开工。
4. 让已有人工标记土豆田先产出实际收获，或按原有流程使居民背包拥有足量普通种薯。没有新的种薯领取命令或自动从仓库拿种子。
5. 撤销用 `/coop settlement planting revoke <x> <y> <z>`。不要求目标仍为空或已加载，不扣除或收回已种作物。

一次许可允许该格现成耕地的播种、成熟土豆采收及留种复种，包括之后玩家在这一格种入的土豆。不是只认居民亲手种的作物；不授权邻格、开垦或其他作物。每营32格、每维度128格，须在营中心水平64格内，水平最近的有效聚落才可使用，等距按聚落UUID稳定选择。

## 留粮、调度与失败

播种前、途中和执行前都重算：居民所有原有可食物的点数，减去这一颗种薯后，仍须达到原来按性格计算的留粮目标（至少12点）。只从实际普通土豆槽扣1颗，不消耗其他食物。基本留粮、途中吃掉或分享掉的物品不会被旧快照重新补回。

进食、玩家会议邀请、借用工具归还、其他材料/用途货物与既有社会预约优先；不强停正在进行的劳动。只有普通余粮时可在返仓前尝试播种，失败后继续原调度。每次有独立100tick退避，搜索仅已有许可中居民水平12格、上下4格内的位置；逐格互斥预约与既有材料任务共用有界协调表，预约不能代替土地许可。

只能从安全同高邻格播种，不走到田上；每轮至多尝试2条路径，保留既有加载范围及节点复验。实际到位后按原性格工作时长处理，基础40tick。不移动、替换手中装备，也不发放虚构产物或技能。

保护区优先。目标作物格、下方耕地和直接相邻区块先检查加载、活动及世界边界，再读方块与生存条件。取消许可、撤销再重授、成员变化、模式切换、身体不适、库存变化或地块被占用都会阻止旧任务扣种。世界放置失败不消耗种薯。库存与世界变更按标准同步、非重入容器执行，不声称跨崩溃原子事务。

## 模式与旧档

survival开启时不进行新播种：标龄收获与抽象TUBERS仍按原权威库存流程保存，不剥离货龄当种子。已许可成熟土豆的采收仍使用原有survival/production门槛及货龄保管规则。默认实物模式的普通土豆种源有限，是首版明确边界。

SowingPlots是根版本24下的可选Version1子树，旧档缺失即没有播种许可。未知版本、错误类型、重复坐标/ID、越界或超限时整块原样保留并停用该子树，命令不清坏数据。在途任务、计时与预约不存盘；重载重新判断，不补种、不补扣。

旧人工资源标记保持独立。只撤销播种许可不会取消另外存在的人工采收标记；需要停止全部CoopCraft采收时，应分别撤销，或使用保护区统一否决。

## 验证边界

本许可只约束本次CoopCraft播种和对应采收路径。原版农民仍可能自行种植、收获，原版分享、繁殖与踩踏也可能改变库存或作物；不能据此声称它们也遵守新土地许可或始终保留12点食物。

回归使用真实ItemStack、BlockState、容器、许可存档及现有采收服务，但世界生长和站位由测试回调提供。首次CI核查构建与单测；没有运行Minecraft、服务器或GameTest。真实导航、田间踩踏、自然生长、多人变化和世界重启留待用户统一验收。
