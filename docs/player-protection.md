# 玩家建筑保护区

这是一层供 CoopCraft 居民生产与施工使用的禁改范围。玩家圈出房屋、屋檐、地基和庭院后，范围内的木石即使已有人工采集标记，也不会被本模组的采集工作拆除。保护优先于资源标记和施工任务，不会给范围外的方块新增采集权。

## 圈定与管理

1. 执行 `/coop protect start "我的房子"`；中文或带空格的名称使用英文双引号。
2. 空手、主手潜行右击第一个地面角点，再右击对角点。
3. 阅读坐标和尺寸预览，执行 `/coop protect confirm` 保存，或 `/coop protect cancel` 放弃。
4. 用 `/coop protect list` 查看本维度保护区，`/coop protect show <ID>` 查看某一区域，`/coop protect remove <ID>` 删除。

默认矩形覆盖两个角点之间的全部 X/Z 列及完整建造高度，包含边界；不必爬到屋顶。角点先后顺序不限。选择状态绑定实际玩家与维度，五分钟失效；离线、换维度也会取消。选区模式会先消费方块交互，避免选中原木、土豆或箱子时顺便触发现有资源/公仓登记。

普通非旁观玩家可创建有限数量的区域，只能删除自己创建的区域；OP 等级2可删除他人的区域。创建者记录不代表系统证明了土地所有权。联机时请与其他玩家协商，不能把此功能当成完整的领地争议处理或防恶意圈地系统。

- 每个维度最多128个保护区，每位创建者最多16个。
- 每条边最多128格，名称最多48个 Unicode 字符。
- 不扫描区域全部方块，也不为圈区加载区块。
- 区域允许重叠；删除一个区域后，另一个重叠区域仍然生效。
- 已有资源标记保留，但在保护范围内不能执行；仍可手动撤销。不能在保护区内新增资源标记。删除保护区可能使原有标记重新有效。
- 此命令独立于聚落，可以保护远离聚落的房子。

## 首版直接拦截的行为

| 行为 | 保护区内的结果 |
| --- | --- |
| CoopCraft 居民砍木、挖石 | 不破坏、不出产，也不借保护状态清理原有标记 |
| CoopCraft 自动采甜浆果 | 不降低成熟年龄，不产生背包浆果 |
| CoopCraft 标记土豆收种 | 不收获、不重种、不扣种子 |
| CoopCraft 居民施工 | 不向保护范围内放置新方块；整个计划占地与保护区相交时暂停工程 |

选择目标、继续工作与真正修改方块前都会读取当前保护。居民已在路上或已经开始工作时新增保护，下一次实际修改仍须通过检查。已经完成的采收不倒退，不回收已有物品；删除保护后须按原有工作条件重新选取目标。

新住宅、工坊与独立火塘选址避开保护区。已有工程保留原位置、任务ID、图纸指纹及施工进度，不能以自动换址或取消工程的方式绕过保护。门、床的第一半和已付费第二半均受约束；已有施工实物可以沿原返仓流程退回，仓满时保留原物和用途标记。保护不会凭空退款或补料。

## 明确不包含的保证

这不是全局领地插件。首版没有改写原版农民的收割/种植、村民踩坏耕地、农业站机器、开门、通行、使用床或工作台，也不提供容器财产保护。登记在保护区内的公仓仍可被既有流程取用。

玩家操作、其他模组、爆炸、火焰、流体、落沙和方块邻接更新不在上述直接写入门禁内。范围外的改动仍可能引发范围内的间接变化；圈区应包含屋檐、支撑和地基，不能只框住室内。不能据此承诺“区内所有方块永远不变”。

居民的资源观察仍是历史候选，来源为 UNKNOWN。`observations suppress` 只抑制观察，不能代替保护区。保护区之外的旧自动浆果行为保留，仍不能自动区分野生灌木与玩家种植。

## 旧存档与损坏数据

旧档（根版本为非负整型0–20，或未记版本）缺少 `PlayerProtectedAreas` 时为空，不猜测老建筑归属，不把人工标记或观察记录转换成保护。根存档版本为21，保护子树独立使用版本1。

未知版本、额外字段、坏类型、重复ID、非法边界或超限数据将整块原样保全，并暂停该维度上述受保护门禁约束的 CoopCraft 村民改块行为，同时拒绝编辑保护数据。根版本21及之后若保护字段整个丢失，也保持缺失并拒绝相关改块，不能通过一次重存自动生成空保护解除阻止；根版本为负数或类型异常且缺字段同样保守处理。原版行为不因此停用。不会静默清空保护来恢复生产；应先备份世界并排查不兼容版本或损坏数据。

升级前备份整个世界，避免用不认识新字段的旧版回写。已有库存、食物时间戳、观察、成员和任务不会因为增加保护区而迁移或重置。

## 验证边界

自动测试检查区域与权限边界、存档往返、损坏保全、真实生产服务的拒绝路径、资源守恒和任务途中更新。源码接线测试用于防止漏接入口，不能代替实体 AI、原版混入、真实重启或多模组测试。具体构建与测试结果见开发记录；按当前要求，不启动 Minecraft 客户端、服务器或 GameTest。
