# 《文明演化》Mod：原始社会的社会组织与行为机制

研究专题 04｜亲属关系、居民心理、习惯制度、社会权力与群体演化

这轮我想重点解决一个之前尚未充分讨论的问题：

为什么一群拥有生存能力的人，会逐渐形成一个有共同生活、义务、习惯、权威和历史的社会？

我们之前设计的居民已经能够采集食物、制造工具、分享产品、学习知识。但这仍然不足以模拟文明。因为社会并不只是许多个体同时生活在一个地方，而是人与人之间存在相对稳定、可以延续并发生变化的关系。

这一次，我建议将社会关系本身正式确立为和生产力、生产关系同样重要的模拟对象。

## 一、本轮调研发现的四个关键问题

### 1. 原始共同体不能简单等同于血缘家族

2011年发表于《Science》的研究分析了32个当代采集狩猎社会，共5,067名个体，发现居住群体中有大量非近亲成员，而且男性和女性都可能离开或留在出生群体。

PubMed

这意味着，我们不能简单设计为：

一个祖先 → 若干子孙 → 一个氏族 → 一个部落。

血缘关系当然重要，但共同居住、劳动合作、婚姻联系、长期友谊和相互照料，也能让没有近亲关系的人组成稳定共同体。

因此，村民至少要有三种互相独立的社会身份：与谁有亲属关系、与谁共同生活、与谁合作和互助。

### 2. 婚育并不必然使女性或男性固定迁往某一方家庭

史前社会的亲属和居住制度并不能被直接还原为单一的父系或母系模式。

相关跨文化研究发现，许多采集狩猎群体具有较灵活的婚后居住方式，夫妻可能住在不同一方的亲属附近，也可能随着生活条件改变而多次迁居。

PMC+1

因此，原始社会不能预设“所有女性出嫁后迁入男方部落”，也不能把母系社会设定为必经的文明等级。

婚姻、亲属身份、居住选择、财产继承必须拆开模拟。

### 3. 平等社会也存在地位差异和利益冲突

2025年11月发表的一项研究提出，与其用财富数字是否完全相同来定义平等主义，不如考察居民能否有效维护自身的资源获取机会、社会地位和自主权。

文章归纳了请求分享、风险共担、限制过度集权、通过合作获得声誉、协商决策和居住迁移等维护相对平等的过程。

Cambridge Core

这说明我们不能用一个“平等程度”数值替代社会制度。

有人拥有威望，并不等于存在阶级；有人拥有较多物品，也不意味着他已经能够控制其他人的劳动。

真正重要的是优势能否变成长期稳定、难以反抗的支配关系。

### 4. 原始共同体不一定有固定的议事会议

这是这轮调研中很容易被忽略的发现。

2025年关于四个非洲采集狩猎群体的比较研究发现，不同群体的决策方式有明显差异。有些群体更强调自主行动，通过个人选择形成集体结果；另一些则存在相对有组织的非正式议事和协调机制。

Sage Journals

所以不能让所有部落每隔七天自动召开一次大会，并通过简单投票决定所有事务。

我们应该同时模拟个人自主决策、非正式协商、临时领导、群体共同行动和规则性会议。

它们各自具有不同的成本与适用条件。

## 二、重新定义村民：他不只是一个有属性的 NPC

我建议原始社会的每个居民都存在五个相互作用的层次。

生物与生活状态

年龄、健康、体力、饥饿、疲劳、照料需求

能力与知识

劳动技能、经验、环境认知、学习能力

个性与行为倾向

合作意愿、风险偏好、自主需求、耐心、冲突倾向

关系与社会经历

亲属、朋友、照料者、合作者、信任、冲突和记忆

社会位置与制度约束

资源使用权、群体身份、习惯义务、声望、组织影响力

这里有一个必须坚持的原则：人物性格可以相对稳定，但人物行为不能固定。

一个通常愿意分享食物的居民，在自己的孩子持续挨饿时，可能拒绝别人的请求。

一个风险偏好较高的居民，经历严重狩猎事故之后，可能变得谨慎。

一个不喜欢参与争论的人，在重要亲属受到不公正对待时，也可能主动组织抗议。

这不是要做成每个村民都拥有复杂语言模型，而是让行为由个人特征、当前处境、社会关系和过去经历共同决定。

尤其需要避免把基因、性别或血统直接写成决定智力、职业、道德和社会地位的固定规则。

## 三、把“社会关系”设计成可以变化的网络

我认为不能用 Minecraft 原版那种单一好感度来模拟人与人之间的关系。

举个例子：甲可能非常尊敬乙的狩猎能力，却不信任乙管理公共粮食；甲与丙是亲兄弟，却已经因为多次争吵而不愿共同劳动。

如果只有一个 `好感度 = 70`，根本无法表达这些关系。

建议将关系分成以下维度：

|关系维度|作用|
|---|---|
|亲属关系|身世、亲属身份、可能存在的照料义务|
|信任|是否相信对方会兑现承诺|
|情感|喜爱、亲近、厌恶等倾向|
|合作经验|共同劳动是否成功、能否配合|
|互助关系|谁帮助过谁，是否存在回报期待|
|社会影响|是否愿意接受对方的建议|
|冲突记录|争端内容、损失、是否得到解决|
|共同身份|是否认同相同的营地、文化或社会规范|

这里还要区分客观事实和个人认知。

例如，村民甲确实帮助过乙，但丙不知道这件事。丙对甲的评价就不应该立即提高。

又如，丙听说甲私藏公共粮食，这条消息可能是真实的，也可能是误传。

系统应允许信息不完整、错误、延迟传播和被质疑。

关于声誉，2023年一项针对 Aka 采集狩猎者、Ngandu 园艺农业群体和其他受试者的研究，专门考察了流言、声誉与资源转移的关系，并指出此前有关其因果作用的实验证据有限。

ScienceDirect

因此，我们可以让传闻影响社会关系，但不能简单设计成“任何人说一句坏话，全村自动降低某人的好感度”。

### 三种关系状态

客观联系

亲属、共同劳动、实际物资往来

主观认知

居民知道什么、相信什么

社会义务

谁应当帮助谁、遵循什么规则

这会让 NPC 的个人经历真正有意义。

## 四、婚姻、家庭与照料系统应该怎么做？

我建议把原始社会的家庭系统拆成四个独立部分，而不是“两个村民结婚，随后自动生孩子”。

第一部分是伴侣关系。 居民可能因为长期交往、彼此信任、个人意愿、亲属联系和生活需要建立伴侣关系。伴侣关系也可能改变或结束。

第二部分是居住关系。 伴侣不一定永久留在原营地，可以在双方亲属附近居住，也可以一起迁往其他营地。居住选择应受到环境条件、照料支持、劳动机会与文化习惯影响。

第三部分是生育与亲子关系。 生物学亲子、社会承认的亲子、实际照料者必须能够区分。生育与健康和人口结构有关，但不能直接成为玩家要求 NPC 执行的生产指令。

第四部分是集体照料。 儿童可能由父母、兄弟姐妹、其他亲属甚至非亲属成员共同照顾。

2024年关于 Agta 与 BaYaka 儿童照料网络的研究发现，非亲属营地成员、兄弟姐妹和未成年成员在幼儿日常接触网络中都占有重要位置，而且不同群体之间存在差异。

PubMed

所以，照料本身应该是一种真实的劳动活动，需要占用时间。

例如：

一位成年人外出采集时，邻居帮助照看孩子。采集者因此有更多时间获取食物，回营后可能提供食物或其他帮助。

这种合作如果持续发生，就能形成长期互助关系。

我们还可以让儿童通过观察照料行为、参与游戏和小规模劳动来学习规范。2017年的一项综述研究综合了33种文化的相关文献，指出儿童的社会规范学习会随成长阶段变化，同伴游戏具有重要作用。

Apollo

这会让儿童真正参与社会生活，而不只是等待年龄增长。

## 五、习惯规则应当怎样从行为中产生？

这是整个原始社会设计中，我认为最需要认真构建的部分。

我们可以把社会规则分成三个层次：

第一层：个人行为习惯

某居民习惯把多余食物分给邻居；另一居民习惯优先保障自己的家庭。

第二层：群体共同期待

多数居民开始期待狩猎成功的人分享部分大型猎物。有人拒绝时，其他人会感到不满、提出请求或减少合作。

第三层：稳定的社会规范

群体形成可识别的分配惯例，即使某位居民不喜欢，也必须考虑违反规则可能带来的社会后果。

这里必须避免一个错误：多数人这样做，不等于全体居民已经认可这是一项义务。

例如，许多人每天早上采集果实，只是一种行为规律；如果群体认为有能力的人应当帮助缺粮家庭，并会对拒绝者作出反应，这才更接近社会规范。

社会规范需要同时有行为内容、适用场景、共同期待和可能的执行机制。

1986年 Robert Axelrod 关于规范演化的计算模型，已经讨论过有限理性行动者在没有中央权威的情况下形成稳定规范的可能性，以及监督规范执行的进一步规范。

Cambridge Core

对于我们的系统，一项规范可以具备如下信息：

|属性|设计例子|
|---|---|
|规范内容|大型猎物应当进行一定程度的分享|
|适用对象|所有营地成员|
|适用条件|获得大型猎物，且存在合理分享机会|
|例外条件|获取者家庭面临严重生存困难|
|支持程度|有多少居民认为该规范合理|
|执行方式|请求、劝说、声誉反应、拒绝合作|
|稳定程度|是否经历多次实际执行|
|历史来源|最初在哪些事件中逐渐形成|

所有这些属性都应该能够变化。

举个例子，某个营地原本习惯共同分享大型猎物，但因食物连续短缺，部分家庭开始更加重视自身储备。其他居民可能要求恢复旧规则，也可能同意增加家庭储藏权。

双方的不同主张必须通过交往、协商和实际行动体现。

## 六、决策不是投票，而是社会协调过程

2026年4月发表于《Philosophical Transactions of the Royal Society B》的一项多智能体模拟研究，考察了婚姻关系、嵌套社会群体与决策规则如何影响共识形成。

其模型发现，社会网络中的家庭聚集可能阻碍信息扩散，而跨群体的联盟或代表性协调方式，在特定模型条件下可以提高达成集体决策的速度。

PubMed

这项研究对我们的程序设计有很直接的参考价值。

我建议把集体决策设计为一个可观察的过程：

1. 提出主张：某居民发现问题，提出迁徙、修建公共设施或改变资源规则。

2. 传播信息：消息通过亲属、合作者、朋友和其他关系网络传播。

3. 形成态度：居民依据自身利益、知识、信任和价值观作出判断。

4. 协调行动：支持者可能自发行动、寻求妥协、组建临时合作群体，或发起更正式的协商。

5. 执行与反馈：最终未必所有人一致同意，有的人可能拒绝合作、另行行动或迁往其他营地。


这种机制的意义在于，它不预先指定部落究竟采用民主投票、长者商议还是个人自发行动。

不同的协调方式会产生不同的成本、效率和社会结果。

例如，面对突发暴雨，群体可能迅速听取熟悉地形的居民的意见；面对公共粮仓的长期管理方式，则可能需要更多轮协商。

共同体不需要把每一件小事都变成政治事件。

## 七、原始社会必须有真实的冲突处理机制

我们不能把共同体设计成一个所有人都友好、永远没有争议的地方。

但同样不能让居民因为一点分歧，就立即进入暴力冲突。

2023年一项比较131个社会的研究发现，不同社会对规范违反行为采用的制裁形式有所差异，且与社会经济组织存在关联。例如，声誉性制裁与较平等的社会结构存在统计关联，物质性制裁则与食物储藏的存在有关。

PMC

因此，第一阶段应该实现一种递进式冲突处理系统。

沟通

解释、请求、拒绝、劝说与谈判

社会干预

亲属调解、声誉反应、群体施压

纠纷处理

补偿、达成约定、修改规则

关系破裂

拒绝合作、迁离、群体分裂

这些并不是冲突必须经过的四个阶段。居民可以直接和解，也可能始终僵持。

更重要的是，处理争议本身要付出成本。

一场长期争议可能减少居民用于生产的劳动时间，破坏互助关系，也可能通过建立新的规则降低未来争端发生的频率。

制度因此不仅仅是一份写在数据库中的规则，而是协调合作、降低或转移社会成本的一套实际安排。

## 八、一个非常重要的新发现：平等的结果不一定来自平等的动机

这是我认为本轮最值得放进研究文库的材料。

2026年2月发表于《PNAS Nexus》的研究，对117名 Hadza 参与者进行了资源分配实验。

实验允许参与者在自己与其他营地成员之间给予或取走资源。研究发现，许多参与者并不主动追求普遍的均等分配，更容易反对对自己不利的不平等，而非所有形式的不平等。研究者据此提出，现实中的分享制度可能部分依赖需求方主动索取和外部社会规范，而不是所有人都有相同的内在公平偏好。

PubMed

需要注意，这是一个具体群体、特定实验条件下的发现，不能推广成所有史前人的普遍心理规律。

但它为我们的模型指出一个极其重要的方向：

我们不应为了得到平等的社会结果，就强迫所有居民具有高度利他的人格。

假设一个营地有三名成员。

甲倾向于为自己积累资源；乙希望在缺粮时获得帮助；丙注重维持共同体关系。

如果乙能够提出合理的分享请求，丙愿意支持群体习惯，而甲又需要维持与其他人的长期合作，那么即使甲并不特别慷慨，也可能选择分享食物。

反过来，假如甲拥有大量储备，其他成员难以取得替代资源，也不能离开营地，那么甲就可能获得更大的谈判优势。

这使我们终于能够把个人利益、社会规范和经济条件放进同一个模型。

## 九、设计一个完整实验：一场粮食争端如何改变共同体？

这一回我们不再假设最终一定出现公共监督或私有制，而是把每个居民的处境具体化。

实验：河岸营地的第二次寒季

虚构模拟情境

初始条件

# 28

营地居民

# 6

共同生活单位

# 1

公共储藏设施

数值为假设，正式模拟中由实际资源、人口和行为状态决定。

三个关键人物

阿洛：经验丰富的食物保管者

负责公共储备。具有较高的技术能力和社会信任，但最近他的家庭也陷入食物短缺。

米娅：负责照料两名幼儿的居民

过去经常帮助其他家庭，最近因为家庭成员患病，无法正常外出采集。

塔恩：年轻的优秀猎人

劳动能力较强，希望家庭能够保留更多狩猎成果。他对公共储备的管理方式持怀疑态度。

事件进程

1. 阿洛发现公共储备正在迅速下降，决定减少食物发放。

2. 米娅请求额外食物，阿洛因自己家庭也面临短缺而拒绝。

3. 塔恩得知此事后，认为此前的储粮管理规则已经失效。

4. 不同家庭开始讨论是否改变领取规则，信息通过亲属和合作网络传播。

5. 居民可能形成不同意见，有人支持阿洛，有人要求优先照顾弱势家庭，还有人提出退出公共储备体系。

6. 他们通过实际行动改变资源分配，影响未来的信任、合作与社会规范。


我们应当保证这个实验可以出现多种结果：

|结果|需要具备的条件|
|---|---|
|共同体达成妥协|双方有足够互信，能够找到可接受的分配方案|
|形成新的公共监督规则|居民支持共同监督，并有能力承担监督成本|
|家庭储备增加|居民认为独立储备更可靠，且具备实际储藏条件|
|保管权趋于集中|少数成员控制关键设施，其他人依赖其调度|
|居民离开营地|外部有可达资源、其他社会关系和迁徙机会|
|共同体持续冲突|各方利益差距过大，缺少有效协调方式|

真正需要做到的是，系统记录每个人为什么作出行动。

例如，塔恩不是因为被随机分配到“反对派”才拒绝公共分配，而是由于自己实际贡献了较多劳动、认为管理失当，而且在外部还有亲属可依靠。

这些条件改变，他的行为也可能改变。

## 十、应该交给开发 Agent 的新一轮机制规格

这轮可以正式形成一套名为 「社会关系与习惯制度系统」 的设计方案。

它需要与现有生产分配系统连接，但不必一次全部完成。

|子系统|需要建立的对象|第一版需要表现的结果|
|---|---|---|
|居民关系|亲属、信任、合作、互助、冲突|不同居民对同一人物持有不同评价|
|家庭与居住|伴侣、照料者、共同居住单位|居民可以组成、调整和离开生活单位|
|社会信息|已知事实、传闻、信息来源|消息需要传播，可能被误解|
|习惯规范|内容、条件、支持者、执行机制|分享规则能够建立、改变或衰退|
|集体协调|主张、支持者、反对者、协商|群体能够作出不同程度的共同决定|
|纠纷系统|原因、当事人、损失、处理过程|居民能够和解、持续争议或迁离|
|历史记录|事件、实际行动、关系变化|可以追溯制度和社会关系的变化|

我建议 Agent 优先打通一条最短的行为链：

居民遭遇实际困难

向另一居民请求帮助

对方根据资源与关系作出选择

双方的物资、记忆和信任发生变化

这些变化影响未来行为

这条行为链能正常运转后，再引入多名居民之间的信息传播、协商以及规范形成。

### 第一阶段的验收条件

我建议至少完成以下六项实验验证：

1. 同一个居民面对不同对象，会因为关系不同而采取不同的分享行为。

2. 同一对居民会因为实际经历改变互信，而非好感度固定不变。

3. 不能让未接触信息的居民自动知道远处发生的纠纷。

4. 共同体可以形成习惯规则，也允许少数人不赞同或违反。

5. 违反规则具有情境化后果，但不能自动导致全体居民统一惩罚。

6. 长期纠纷能够影响劳动合作、迁徙和群体成员组成。


通过这些测试，才能证明社会关系真正参与了经济与历史演化，而不是附着在 NPC 身上的装饰数据。

## 十一、这轮研究仍然需要谨慎的三个问题

第一，现代采集狩猎群体并不是史前人类社会的原样复制。考古证据、民族志和理论模型必须互相参照，不能将某个现代群体的习惯当成所有原始社会的普遍规律。

第二，平等、亲属和权力关系本身存在学术争论。例如，2026年10月的相关学术评论就提醒我们，不能因为某个社会拥有资源分享和集体决策机制，就忽略其内部可能存在的性别权力差异。

PubMed

第三，模型中应当区分历史证据与设计假设。居民信任值怎样改变、规范需要多高支持度才能稳定、争议多长时间可能导致迁徙，这些目前都只能作为待校准的程序参数，不能包装成确定的历史定律。

## 本轮结论与下一步

现在，我们的原始社会设计已经从生产经济扩展到社会生活的核心部分：

个人需求产生行动，行动改变人际关系，人际关系形成合作与冲突，长期实践产生习惯，习惯又反过来影响下一代人的生活。

它与此前的生产力和生产关系系统结合之后，才可能出现真正的历史演化。

下一项我认为最值得深入研究的是原始社会的文化、认知与技术创新系统，特别是语言和信息传播、知识的发明与遗失、仪式和群体认同，以及文化如何影响劳动、婚育、财产和权力制度。

这还将帮助我们回答一个非常重要的问题：为什么两个拥有相似自然环境和生产技术的群体，经过几代人之后，可能发展出明显不同的社会生活方式？

等这些问题研究清楚，我们就能够逐步形成一份不仅涵盖经济制度，也涵盖人类完整生活的原始文明设计总纲。
