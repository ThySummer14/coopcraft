# 《文明演化》Minecraft Mod：总体研究与系统设计

第一轮研究报告｜历史唯物主义 × 多智能体社会模拟 × Minecraft

我认为这个项目最有价值的地方，不是让 Minecraft 中的村民从石器时代一路发展到工业社会，而是尝试实现一个更复杂的目标：

在一个具有真实物质条件、社会关系和个体行为的世界里，让人类社会的组织形式自行产生、发展、发生矛盾，最终走向变化。

玩家能够见证一个原本共同劳动、共同生活的小部落，如何逐渐出现财富差异、私有财产、阶级、政治权力与国家。也可能看到它坚持公有制度，出现不同形式的分工和管理组织，或者在发展过程中遭遇危机、分裂、改革与革命。

这意味着我们设计的其实不是普通的文明升级 Mod，而是一套运行于 Minecraft 世界中的历史唯物主义社会模拟系统。

## 一、首先确定一个最根本的设计原则

普通文明游戏的逻辑

石器时代 → 青铜时代 → 封建时代 → 工业时代 → 现代

满足科技条件，解锁下一个时代

我们需要的逻辑

生产力、资源条件、人口与技术

所有制、分工、劳动组织与产品分配

阶级关系、制度、国家、法律与观念

个体与群体持续互动，产生矛盾、调整和制度变迁

这套设计有明确的理论依据。

马克思在1859年《政治经济学批判》序言中，论述了生产力、生产关系、经济基础与上层建筑之间的关系，并强调当生产力与既有生产关系发生冲突时，可能进入社会变革时期。

马克思主义者互联网档案馆

但有一个必须注意的理论问题：

不能将原始社会、奴隶社会、封建社会、资本主义社会、社会主义社会设计成所有文明都必然经过的五个关卡。

在1881年致查苏利奇的信及草稿中，马克思讨论过俄国农村公社在特定历史条件下不必完整重走西欧资本主义发展道路的可能性。现代考古学研究同样强调，社会政治演化并非整齐划一、不可逆转的线性过程。

marx-ebooks.github.io+1

因此，我建议保留你提出的社会形态作为主要研究框架，但在程序中将它们视为不同生产关系与制度结构的组合，而不是固定时代等级。

同样的技术水平，可以存在不同社会制度；同一个国家内部，也可以长期存在多种生产方式。

这会直接决定整个 Mod 的深度。

## 二、现有游戏与研究：我们能够借鉴什么？

目前没有发现一款能完整覆盖你描述的所有目标的 Minecraft Mod。不过，已有一些项目分别解决了其中的局部问题。

MineColonies

参考重点：居民职业、生产链、殖民地管理

它具有居民岗位、建筑、物资供应与管理系统。可以研究它如何组织村民劳动，但它的核心是玩家管理殖民地，而不是社会制度自行演化。

Minecolonies

MCA Reborn

参考重点：个体、家庭、婚姻、生育、遗传

它已经实现较丰富的村民关系和代际系统。我们值得借鉴其NPC交互思路，但还要进一步把家庭与经济利益、阶层再生产联系起来。

Minecraft Mod

TerraFirmaCraft

参考重点：生产力与自然条件

它重构了采矿、冶金、农业、食物腐败、季节和技术发展。这些机制能让生产力的提高有真实物质基础，而不是简单增加一个科技数值。

Minecraft Mod

Victoria 3

参考重点：经济、人口群体、利益集团、制度改革

游戏把人口需求、劳动、产业、法律、政府和政治诉求联系在一起。它非常适合参考社会层面的系统设计，但我们希望比它更强调个体到制度的自下而上生成。

Paradox Interactive

Dwarf Fortress

参考重点：世界历史、人物经历、模拟分层

它会显式追踪重要历史人物，同时抽象处理世界中大量其他人口。这个设计尤其值得我们学习，因为 Minecraft 无法让上万个村民始终作为完整实体运行。

Dwarf Fortress Wiki

还有一项更直接的科研参考。

1996年，Joshua Epstein 和 Robert Axtell 在《Growing Artificial Societies》中介绍了 Sugarscape 模型。

它从拥有不同代谢、感知与行动能力的简单个体出发，通过资源获取、贸易、繁殖、文化传播等规则，让财富差距、群体分化和复杂社会现象逐渐产生。

这与我们要做的“从村民行为中生成社会”高度相似。

MIT Press+1

这些参考最终指向一种设计方法：

自下而上的多智能体模拟（Agent-Based Modeling，ABM）+ 自上而下的制度约束。

社会不是只有村民在行动。村民创造了制度，制度又反过来限制和塑造村民的行为，两种过程必须同时发生。

## 三、整个 Mod 应当由哪些系统构成？

我建议先确立十个长期核心系统。它们之间相互依赖，却不应该一次性全部实现。

|核心系统|需要模拟的内容|
|---|---|
|1. 自然与资源|土地、水源、矿物、气候、灾害、资源枯竭|
|2. 生产力|工具、技术、劳动效率、知识积累、能源|
|3. 生产关系|生产资料所有权、分工、雇佣、依附、强制劳动|
|4. 经济与分配|库存、消费、交换、货币、价格、工资、税收、计划|
|5. 社会组织|家庭、氏族、部落、行会、企业、合作社、阶级|
|6. 政治与制度|权力、法律、国家、行政、政策、政治组织|
|7. 居民个体|性格、需求、能力、记忆、关系、家庭、继承|
|8. 教育与文化|知识传播、学校、观念、传统、意识形态|
|9. 社会冲突|利益竞争、协商、罢工、反抗、战争、制度改革|
|10. 历史演化|人口变迁、技术扩散、文明交流、兴衰与历史记录|

这十个系统中，我认为最容易被低估的是第三个：生产关系。

一个游戏即使有极其复杂的农业、钢铁、蒸汽机和工厂，也不一定是社会模拟游戏。

真正决定其社会形态的是：谁拥有工厂？谁决定生产什么？谁提供劳动？谁获得产品？谁能够改变这些规则？

### 3.1 生产关系与所有制

不能简单地给村民设置一个 `privateProperty = true` 属性。

我们至少需要将财产权细分为以下几种权限：

|权限|例子|
|---|---|
|使用权|可以使用这块农田|
|收益权|可以获得土地生产的粮食|
|管理权|可以决定土地种植什么|
|排他权|可以禁止其他人使用|
|转让权|可以出售或赠与土地|
|继承权|可以把土地传给后代|

例如，一个农民可能拥有土地的使用权，但必须把部分产出交给领主；一个工厂工人可能操作机器，却不拥有机器；一个合作社成员则可能共同拥有管理与收益权。

而私人所有、氏族共有、村社共有、国家所有、合作社所有等，都应当是这些权利的不同组合。

个人用品与生产资料也必须区分。 一位村民拥有自己的衣服和生活用品，并不意味着村庄已经产生以私人占有生产资料为基础的经济制度。

### 3.2 经济生产与分配

分配机制不能仅仅通过“平均分配”“按劳分配”“市场分配”几个按钮切换。

所有形式的分配，都应当依赖实际生产和资源约束。

假设一个村庄一个生产周期收获了120单位粮食：

|用途|数量|
|---|---|
|下期播种留种|15|
|生产设施和公共储备|20|
|学校、公共事务等|10|
|家庭消费|75|
|合计|120|

这是一个示例模型，不是某种制度的固定分配公式。

在公社经济中，75单位粮食可能依据家庭人口、需要或共同商议规则分配。在市场经济中，这些粮食可能进入交易体系，居民凭收入购买。在存在地租或税收的社会中，产出还可能先按照所有权和法定义务发生转移。

这里最重要的是：分配制度不仅改变居民最终拿到多少东西，还要改变谁能控制生产和剩余产品。

马克思在《哥达纲领批判》中，专门区分了生产条件的分配与消费资料的分配，并讨论社会总产品中再生产、公共服务和保障基金的扣除问题。这对我们的经济系统很有指导意义。

### 3.3 阶级不应该是村民出生时的职业标签

一个社会可以有农民、工匠、士兵、商人，但这些岗位并不自动对应特定阶级。

我建议把阶级地位设计为计算结果，而不是简单预先赋值。

例如，系统需要根据居民及其家庭的以下情况分析其社会位置：是否拥有重要生产资料、是否主要依靠出售劳动力生活、是否取得地租或利润、是否可以支配他人劳动，以及在制度中享有什么权利。

这样才可能出现一种有趣的情况：

一位最初靠自己劳动生活的工匠，改进了生产工具，逐渐扩大作坊，雇佣其他村民劳动。多年后，作坊由他的子女继承，家族获得持续的经济优势。

系统不需要突然告诉他“你现在成为资产阶级了”。

他的生产关系已经改变了。

同时也要允许破产、社会流动、合作社化、重新分配财产等反向变化。

### 3.4 国家需要有实际的运行成本

一个部落有首领，并不意味着已经出现国家。

可以把国家形成理解为一组制度能力逐渐稳定化的过程，例如：

- 是否具有相对稳定的领土与人口管辖范围；

- 是否建立持续征税或征收公共资源的能力；

- 是否拥有专门的行政、司法与执行机构；

- 是否形成超出个人威望和亲族关系的正式规则；

- 是否有维持这些机构所需的资源与组织能力。


这里值得研究2025年的一项跨文化研究。研究者分析了868个文化样本，结果支持谷物种植的可征税性与国家形成之间存在重要联系，并考察了税收和文字的关联。这提醒我们，粮食剩余并不是国家诞生的充分条件，剩余是否容易被控制、储存和征收，同样关键。

PMC

因此，Minecraft 中的一座粮仓也许不仅是建筑。

它可以成为经济组织、财产权力、征税能力乃至国家形成的关键物质基础。

## 四、最重要的机制：让历史事件自然发生

以你提到的“部落首领、生产力提高、剩余产品、私有制和第一个国家”为例，我试着把它转换成一段真正可以运行的模拟过程。

模拟实验：河谷部落的诞生与分化

假想推演

初始条件：40位居民、河流、耕地、森林、石器技术、氏族共同管理粮食

1. 生存与合作

    居民按能力采集、狩猎、耕作。粮食主要由氏族共同储存。威望较高的居民负责协调，但没有永久的财产支配权。

2. 生产力变化

    工匠改良工具，农田单位劳动时间产出提高。粮食出现可储存剩余。部分居民逐渐脱离直接农业生产，承担运输、管理和工具制造。

3. 管理权集中

    由于粮食规模扩大，原有的轮流保管变得低效。部落委托一名能力较强、具有威望的居民管理粮仓。他逐渐控制仓库钥匙、出入记录及储备调度。

4. 利益分化

    粮仓管理者可能为亲属优先分配粮食，也可能利用储备借贷获取回报。部分家庭积累更多财产，其他家庭则因歉收形成依赖。

5. 制度冲突

    部落内部出现不同主张。部分居民希望继续共同管理仓库；富裕家庭可能支持家族继承管理权；贫困居民则要求重新分配。

6. 社会演化分叉

    最终的结果由各方资源、组织能力、观念、外部威胁以及制度规则共同决定，不直接指定某个文明阶段。


同一段历史，可能出现三种不同结果：

公社延续

村民建立共同监督、轮换管理和公共审计，防止仓库被私人长期控制。

权力集中

管理职位世袭，征收制度稳定，出现专职官员和执行组织。

部落分裂

居民不接受分配规则，一部分家庭迁移，建立新的定居点。

如果我们希望进一步出现奴隶制，就需要在模型中增加战争俘虏、债务依附、强制劳动、执行成本、社会认可或反对等具体条件。

产生剩余不必然产生奴隶制；出现奴隶也不意味着整个社会就是以奴隶劳动为主要生产基础的奴隶社会。比较史研究恰恰强调，不同形式的非自由劳动制度具有复杂且并不统一的历史轨迹。

Cambridge Core

标志性事件应当是历史结果的可见化，而非历史变化的隐藏开关。

例如，第一部成文法、第一次定期征税、第一支常设卫队、第一份可继承土地契约，都可以进入文明史书。但这些事件必须由实际制度变化触发。

## 五、六种主要社会形态如何建模？

这里把你提出的六种形态暂时整理成不同的研究方向。它们只是典型模型，实际游戏中的经济和制度应当允许混合、并存与转变。

|典型社会形态|应当重点体现的机制|
|---|---|
|原始公社或氏族社会|亲属关系、共同资源、互惠劳动、集体决策、习惯规则、公共储备|
|奴隶制占重要地位的社会|人身不自由、强制劳动、劳动控制权、财产与权利等级、抵抗和逃亡|
|封建或领主制社会|土地控制、地租、劳役、依附关系、等级义务、封地及地方权力|
|资本主义社会|私人资本、雇佣劳动、商品市场、工资利润、资本积累、竞争与危机|
|社会主义社会的不同制度形式|生产资料公有或合作所有、公共投资、不同计划与市场协调方式、社会保障和经济治理|
|共产主义高级阶段的理论模型|发达生产力、共同生产、劳动角色转变、按需分配的物质条件与公共事务协调|

这里尤其需要把资本主义、社会主义和共产主义的实现研究得更细。

资本主义的关键不是有商店或货币，而是生产资料占有与雇佣劳动关系，以及资本积累和再投资。马克思在《资本论》第一卷关于原始积累的分析中，特别讨论了劳动者与生产资料相分离的历史过程。

Chapter Twenty-Six

社会主义则不能用简单的“所有人收入相同”来表示。我们应该把生产资料所有制、经济协调方式和政治治理方式作为三个能够相互组合的维度。

例如，同样存在公共所有制的社会，可能采用不同程度的集中计划、地方自治、合作社管理或市场交换。其运行效果受到信息、产能、供需、执行能力、利益冲突和资源限制的影响。

关于共产主义高级阶段，马克思在《哥达纲领批判》中讨论的是在生产力发展、社会分工和劳动性质改变等条件下实现按需分配，而非通过颁布一条法律自动进入理想状态。

## 六、村民系统：每个人都应当有自己的一生

你提到的性格、特质、教育和基因系统，是让社会模拟不至于变成冰冷数字游戏的关键。

我建议每个重要居民拥有四类不同的信息。

|层面|数据与机制|
|---|---|
|生物与家庭|年龄、健康、亲属、代际关系、部分可遗传表型|
|个性与经历|冒险倾向、合作性、耐心、信任、重大事件记忆|
|能力与教育|劳动技能、经验、识字、知识、学习机会|
|社会与经济|职业、财产、收入、社会关系、制度权利、价值观念|

遗传系统与社会继承系统应当分开。

例如，外貌等部分生物特征可以有遗传规则，但“一个人的聪明程度必然由血统决定”不适合成为底层规律。知识和技能可以受训练、生活条件、教育资源等多种因素影响。

比起单纯模拟基因，更重要的是模拟代际优势如何被延续。

一个富裕家庭可能让孩子接受更长时间的教育，提供工具和学徒机会，并传承土地或作坊；贫困家庭的孩子可能更早开始劳动，因而获得不同的技能与发展机会。

这会进一步影响婚姻、迁移、职业流动、财富分化和下一代的社会关系。

### 村民作出决定的方式

我们可以给居民建立一个有限理性的决策模型：

\[ U(a)=w_1S+w_2I+w_3R+w_4B-w_5C \]

其中，行动 \(a\) 的效用综合考虑生存保障 \(S\)、预期利益 \(I\)、社会关系 \(R\)、个人信念 \(B\) 与成本风险 \(C\)。

不同村民的权重各不相同，并会随着经历改变。

一个极度缺粮的村民可能选择签订不利的劳动契约，而拥有充足食物储备的村民可能更愿意承担政治改革或迁移的风险。

但这里不能只用个人效用决定历史。组织、法律、传统、信息不对称和强制力都需要进入模型，否则复杂的阶级与国家制度会退化为村民之间的简单交易。

## 七、教育、观念与上层建筑不能是装饰品

这是项目中另一个有意思的研究方向。

制度由社会关系塑造，也能持续改变人们的行为与观念。

比如，当一个社会建立学校之后，学校不应该仅提供固定的生产效率加成。

教育需要消耗教师劳动、建筑、教材和社会资源。它既可能传播农业、冶金和医学知识，也可能传授法律、文化、历史叙事与社会规范。

不同教育制度可能产生不同结果：识字率提高，技术扩散加快，传统观念被继承或质疑，新职业得到发展，原有权力关系获得支持或遭遇挑战。

制度本身也应该有历史惯性。即使社会经济条件发生变化，某些法律、习惯和组织仍可能长期保留，而不是立即随着经济数据变化。

关于公共资源管理，诺贝尔经济学奖得主 Elinor Ostrom 的研究值得专门纳入资料库。她研究了共同资源使用者如何通过规则、监督、参与和冲突解决机制维持集体治理，能够帮助我们设计不依赖中央政府的公共制度。

## 八、怎样让它依然是一款好玩的 Minecraft Mod？

这里必须区分两个目标：

模拟系统需要足够真实，但玩家不能因此被迫阅读数十页经济报表。

我倾向于将玩家设计为社会中的行动者，而不一定是社会的绝对统治者。

玩家可以是一名普通猎人、工匠、农民，也可以通过长期积累成为有影响力的商人、部落首领、政治组织者或政府成员。

玩家制造一件新工具，可能改变一个村庄的劳动效率；向别人传授技术，可能改变当地职业分工；建立公共仓库，可能改变物资分配规则；如果试图控制所有土地，也可能遇到居民抵抗。

玩家不应拥有无条件切换国家制度的权力。即使玩家成为统治者，也需要相应的社会支持、资源和执行能力。

### 我建议重点设计三个可见界面

居民档案

查看一位村民的家庭、工作、财产、受教育经历、政治态度与人生记录。让玩家认识社会中的具体人物。

社会观察台

展示实际产量、劳动人口、所有权、贫富分布、公共库存、制度与社会关系，而不是单一文明等级。

文明编年史

记录谁发明了工具，谁建立第一个作坊，何时出现第一次土地纠纷，以及某项法律为什么诞生。

我尤其看好文明编年史。

系统可以将统计变化与具体人物联系起来，自动组织成有因果解释的历史记录，而不是只随机生成故事文本。

例如：

河谷历 第38年 · 秋

第一次土地争议

工匠伊文的家族连续三年负责东岸的农田修整。他提出应由其家族长期享有这片土地的收益权。

在随后的氏族会议上，17人支持维持土地共有，9人支持伊文的提议，另有6人没有表态。

会议决定暂缓处理争议，但允许伊文一家保留更多当季收成。

模拟事件示例：日后的私有制萌芽可能来自这项看似临时的决定，也可能在下一次会议中被撤销。

当历史变化能够追溯到某个人、某块土地、某项制度和某次决定时，玩家才会真正感受到社会正在演化。

## 九、技术实现：不要把全部社会运算塞进村民 AI

这部分决定项目最终能发展到什么规模。

我的建议是，把整体架构拆成三层：

Minecraft 表现与交互层

实体、方块、建筑、动画、GUI、玩家行为

独立社会模拟核心

人口、经济、制度、组织、决策、事件与历史

数据、配置与持久化层

存档、生产规则、政策定义、技术、统计与事件日志

核心社会运算最好写成尽量不依赖 Minecraft 引擎的 Java 模块。

这样我们就能在不启动游戏客户端的情况下，用自动化测试模拟数十代人的社会发展，并检查不同制度是否产生了符合模型规则的结果。

### 9.1 居民必须采用混合模拟

靠近玩家的居民是真正的 Minecraft 实体，可以走路、种田、建造、交易、讨论和执行行动。

远离玩家的居民仍然拥有身份、财产、家庭和社会关系，但不必实时运行完整寻路和实体 AI。系统可以以较低频率计算其劳动、消费、迁移和家庭事件。

大规模背景人口还可以进一步聚合为家庭或人口群组。

这是为了避免数千个村民同时运行复杂 AI，把服务器拖垮。

对于 NeoForge，官方已经提供实体和世界数据附加机制，以及用于保存全局社会状态的 SavedData 系统，可以作为持久化基础。

GitHub+1

### 9.2 模拟应当采用不同频率

|更新类型|建议节奏|
|---|---|
|实体行动、附近玩家互动|游戏实时|
|工作安排、每日消费、库存变化|每个游戏日|
|商品交换、市场价格、公共分配|每个经济周期|
|家庭重要决定、组织协商|按事件触发|
|政治改革、技术扩散、社会形态分析|较长周期|
|历史档案、统计快照|重要事件或定期保存|

这些都只是初始技术建议，最终需要通过性能测试校准。

另外，系统要有严格的物资账本：不能凭空复制粮食，不能让货币交易自动创造物质产品，不能让人口增长完全脱离食物与居住条件。

涉及产业生产时，需要计算资源投入、产品产出、工具损耗、运输成本、劳动时间与环境影响。

只有底层经济守恒可靠，后面的社会演化才有可信基础。

## 十、开发路线：先完成一个能够证明理论的最小世界

我不建议开始时就制作六个完整社会阶段、几百种机器和几十套国家制度。

我们应该首先证明：一个小型社会可以在没有固定升级脚本的情况下，产生不同的财产关系、劳动组织和制度变化。

第一阶段开发规划

建议的原型范围

# 40–80

# 1–3

个相互联系的定居点

# 3

种基础财产管理模式

|   |   |
|---|---|
|原型 A|居民需求、采集农业、劳动分配、粮食储备与人口延续|
|原型 B|工具改进、技术传播、分工与生产剩余|
|原型 C|个人、家庭、集体财产及权利转移|
|原型 D|集体决策、利益冲突、规则制定与执行|
|原型 E|历史事件、制度变化、分化与分裂的可观察结果|

原型完成后，应该进行多次不同随机种子的模拟实验。

比较的不是哪个文明“进步最快”，而是在不同生产条件、资源分布、人口关系和制度规则下，出现了哪些社会组织，以及为什么。

如果一百次模拟中，每一次都必然在第30年产生私有制、第50年产生奴隶制、第80年建立国家，那么即使画面再精美，历史模拟仍然只是预设剧本。

相反，如果存在可解释的分化、延续、失败、改革和回退，而且系统能说明背后的原因，第一阶段就成功了。

技术选择上，我会优先评估 Minecraft Java 版 1.21.1 + NeoForge 的原型组合。该版本能找到 TerraFirmaCraft、Create、MCA Reborn 等相关模组资源，可以方便研究兼容和机制参考。但是否采用这些模组作为依赖，还要逐一核对版本、性能、API和许可。

更长期的方案应尽量保持核心模拟独立，减少因 Minecraft 或模组加载器更新造成的大规模重构。

## 十一、需要避免的四个问题

|问题|我建议的处理方式|
|---|---|
|理论变成时代升级树|社会形态由实际生产关系与制度诊断，而不是强制解锁|
|社会历史完全随机|所有重大事件必须有条件、因果链和可追溯记录|
|模拟复杂到不可运行|独立核心、混合人口模拟、分层更新、自动化测试|
|制度被写成预定结局|区分理论假设、模拟规则与历史证据，允许不同制度在特定条件下展现各自优势和问题|

还需要有一个单独的研究工作流：每个重要机制都标注其理论来源、历史参考、游戏化假设和测试方法。

例如，“粮食的可征税性影响国家形成”可以有对应研究依据；但“当可征税资源达到某个具体数值便自动成立国家”，只能是一条人为设计的游戏规则。两者不能混为一谈。

这会使项目拥有较扎实的学术基础，也更方便日后扩展和修正。

## 最终建议

我认为，这个项目最值得坚持的设计思想可以概括成一句话：

不要直接制作六种社会，而要制作能够产生这些社会形态的条件、行为和制度。

真正需要优先开发的不是奴隶制建筑、封建城堡或现代工厂，而是人的生存需求、劳动生产、资源控制、财产分配、社会协作和利益冲突。

当这些基础成立之后，很多原本需要开发者手工编排的故事，就有机会成为模拟世界自己的历史。

我还建议把整个项目分成两个长期并行的成果：一个是可以独立运行、用于实验的社会模拟引擎；另一个是让玩家能够生活在模拟结果之中的 Minecraft Mod。前者保证研究深度，后者保证可玩性。

这会是一个很庞大的长期项目。不过它已经有了明确的第一步：先让一个几十人的原始聚落，在真实的生产、分配和协商中，自行走出不止一种历史。
