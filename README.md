# CoopCraft

[![build](https://github.com/ThySummer14/coopcraft/actions/workflows/build.yml/badge.svg)](https://github.com/ThySummer14/coopcraft/actions/workflows/build.yml)

和朋友一起开发的 Minecraft Fabric 联机模组。

## 功能

- **共享进度播报**：队友达成进度时，你的屏幕上也会弹出同一个成就 toast。

  原版只会在聊天栏广播一条公告，toast 只有达成者本人能看到；装了这个模组之后，
  同一服务器上的所有人都会一起看到弹窗。配方解锁（`minecraft:recipes/...`）不会触发，
  避免捡到新物品就刷屏。

- **队友坐标分享**：按 `V`（可在“控制”里改）把当前坐标和维度发到队友聊天栏，
  点击聊天里的坐标可以直接复制。

- **队友死亡点**：队友死亡时，死亡坐标和维度会发到其他队友的聊天栏，
  点击坐标复制，方便回去帮忙捡装备。

- **共享路径点**：按 `N` 给脚下这一格起个名字，全队就能在聊天栏里看到它；
  按 `M` 随时列出所有路径点，显示所在维度、坐标和直线距离，点坐标复制、点「删除」移除。
  路径点存在世界存档里，下界、末地的点会标注各自维度，重开服务器也还在。
  `/coop waypoint add|remove|list` 也能用，适合写进命令方块或快捷键。

- **自动农艺机**：每 2 秒收割并补种周围 3×3 的一株成熟作物，支持小麦、胡萝卜、
  马铃薯、甜菜和下界疣。把箱子或其他容器放在机器正上方即可收集产物；空间不足时不会
  收割，并会提醒附近玩家。右键机器可查看状态，在红石创造物品栏中也能找到。

- **文明聚落名册**：钟附近32格内有至少 2 名尚未登记归属的有效村民时，非潜行右击钟可以建立聚落。
  聚落名称、中心和创建日会保存在世界中；再次右击钟可查看当前已加载居民、职业和位置。
  附近的钟会归入同一个聚落，潜行右击保持原版行为。

- **原始共同聚落**：新建聚落与旧存档聚落默认采用原始共同制度，技术时代与社会形态分开记录。
  生产资料共同所有，村民共同劳动并把采集及加工成果送入公仓；手持工具是成员使用物品，不算生产资料私产。
  右击钟打开的名册会显示社会形态、所有形式、劳动与分配规则。本阶段没有货币、税收、法律、国家或自动社会演进。

- **人格、组合特质与部落首领**：每名成员拥有稳定的勤劳、自私、社交三维数值，以及一种人格和 2–4 项特质，
  全部由 UUID 确定并随成员存档，互斥特质不会同时出现。人格包括诚实、狡诈、雄心、知足和和平主义者；
  特质包括贪婪、慷慨、暴食、敏捷、迟缓、强壮、虚弱、睿智、快建、慢建、外貌与运气等。
  它们分别影响口粮、采集、制作、施工、移动速度和首领竞争，幸运不会额外生成资源。首领失效时由首领竞争分最高的
  已加载成年成员继任；有效首领不会被随意替换，也没有私人仓库或生产资料特权。名册以三行居民卡片展示完整组合。

- **公共火把的真实生产**：住宅缺照明材料时，居民会到公仓领取煤或木炭与木棍，带到登记工作台制作4支火把，再实际返仓。沿用已有配方与施工需求，燃料仍需真实供应；详见[工作台生产](docs/workbench-production-logistics.md)。

- **居民结伴学习工艺**：开启生存、技能与规范映射后，居民会在完成手头工作、处理吃饭和返仓后寻找附近同营资深工匠，双方走到登记工作台共同学习。只有持续实际同场才提升学徒CRAFT，双方各付1小时社会工时，每人每天一次；途中失效或重载取消。原有 `/coop settlement teaching` 现场查看和明确组织仍可用，详见[现场教学](docs/field-craft-teaching.md)。

- **可选择的备粮目标**：`/coop settlement reserves` 查看本聚落库存与补粮目标；OP可用 `normal` / `high` 在常规与加倍目标之间切换。目标只影响觅食者下次是否继续补储备，实际收获仍消耗劳动时间并占用其他工作的机会；它不预留食物、不增加口粮额度，也不保证更多收成。

- **居民独立界面**：普通主手右键本地登记成员打开可滚动资料窗口，提供尝试赠送当前主手1件食物、明确邀请/取消、审阅后召开真实仓库会议和刷新；会后回执及本人当日取粮记录可直接核对。每次操作由服务端重验，重复请求不重复赠送，关闭后的旧更新不会重开窗口。潜行快捷方式、非成员原版行为及名称牌等重要物品仍保留；不支持新窗口协议的客户端降级为原聊天查看。具体边界与验收见[聚落命令](docs/settlement-commands.md)。

- **面对面补充公粮**：普通右键居民可看当前备粮目标与缺口；主手持食物潜行右键可提议赠送1件。居民结合公仓目标、饱食、信任和性格回应，成功才从当前主手扣1件入公仓并记住援助；提高目标不保证满腹居民愿意接受，也不会立即让对方吃饱。

- **现场公仓议事**：开启生存与规范映射后，可在真实公仓旁用 `meeting hold` 组织已有议题。至少两名现场且有社交工时的成年决策者才讨论，每聚落每核心日最多一次成功会议；居民自行形成立场，玩家不指定结果。参与率仍以有效成年人口为分母，讨论成本影响下一日既有采集/加工时间。 `meeting` 会说明当前议题的基础额度或照护加额，`hold` 后可对照本轮真实票数与结果原因，再用 `rations` / `events` 检查实际执行。 新生成的基础额度提案从当前有效基础额度计算；无有效规范时以实际默认3件为起点。家庭储备富余仍可提出减额，旧开放提案不会被自动改写。

- **面对面邀请赴会**：普通右键可询问最早待议提案的知情、介绍能力与当前意见依据，再空手潜行右键合格成年居民，邀请其忙完当前动作后走到公仓；饥饿、受伤或正在进食者先处理自身需要。实际到场才等待，邀请有固定时限，仍须玩家在现场通过居民窗口或 `meeting hold` 召开，不会自动投票或远程召开。

- **日终饥饿与社会反应**：实际在场居民在相邻日终仍达到主动进食门槛时，会积累可保存的观察记录，接入既有短缺纠纷、不满与提案机制。窗口显示最后观察核心日、记录的连续日数及当前不满；缺席、关闭或离线间隔不补算。持续饥饿不等于公仓为空，首次纠纷也不保证立即产生提案。

- **规则调整后的再次取粮**：同一核心日因个人份额用尽被拒、仍未达到进食目标的居民，在额度实际提高且公仓有粮后，可以重新发起到仓进食。窗口把当时拒绝记录与当前条件并列显示；仍须真实抵达、排队及扣库存，旧拒绝不能重置已领件数，也不保证补领成功。

- **补货后接着吃饭**：居民实际吃到公仓耗尽、当时仍有日额度时，会留下中断餐记录。同日实际补货后，可按当前额度重新到仓；窗口区分这餐的缺粮记录与制度拒绝，不凭空扣信任或加不满，旧餐不会重复提供领取额度。

- **撤销采集立即生效**：木石资源取消标记后，在途或尚未完成的采集不再有权破坏该方块；执行前重新核对当前成员、聚落归属、标记、区块与木石劳动机会。重新标记可供下一次正常选取，不会凭旧计划继续出产。

- **议事也影响施工时间**：会议支付的社会工时在下一次日结后也会拖慢盖房，居民窗口可查看本日投入与上轮工时系数。玩家需要权衡邀请谁参会和让谁维持生产；未参会居民的工时不因此改变。

- **新住宅工地检查**：开建前检查整块地基支撑、屋内净空及门外落脚空间，支持同高直线门廊中的内退门；不会挖地或覆盖已有方块。`/coop settlement construction sites` 可只读查看候选地点及原因，现存工程保留原工地。先选原同高候选，再检查上下各一格的平整台地；仍不支持坡地地基或全程寻路保证。

- **监督需要可用居民**：真实领取排序和监督记账只选已加载、活动区块内且位于聚落中心64格内的成年成员。支持者离场会影响需求排序和监督工时，已采纳的每日额度仍有效；这还不是要求站在仓旁的驻守行为。

- **到仓需求优先窗口**：生存与规范映射均开启、需求优先规范有效时，已到仓并完成进食准备的居民在固定40 tick窗口内按需要排序取粮；无有效规范沿用原立即进食。只对本轮真实到仓者排序，不预扣库存，停止/离仓/跨日会取消，重载后重新准备。此窗口不保证所有场景普遍更优。

- **聚落仓库与口粮分配**：建立聚落后，潜行右击附近的箱子或木桶可设为公共仓库。
  村民上缴原木、圆石、木棍、平滑石头及多余食物；基本口粮需求通常为 12 点，暴食者为 16 点。
  多余口粮的保留由自私数值、人格和贪婪/慷慨等特质共同决定，但缺粮时只补到个人基本份额，公共生产物仍全部上缴。
  名册直接显示公仓实际食物点数与公共生产物数量，不用抽象数值伪造剩余。仓库已满时物品留在村民背包中，缺粮时不会凭空生成食物。

- **饱食与真实进食**：每名成员拥有 0–100 饱食度，旧成员默认 80；已加载且在聚落范围内的成员每 600 tick 减少 1 点。
  饱食不超过 35 时，成年村民与儿童会优先前往公仓，每次吃一个真实食物，优先消耗背包，再消耗公仓，
  按原版食物点数恢复 5 倍饱食，直到达到 95 或食物耗尽。饱食低于 20 时工作时间增加 25%，名册显示个人饱食度。
  当前不会饥饿致死，也没有情绪或离线代谢模拟。

- **安全甜浆果采摘**：年龄2/3的成熟灌木仅在背包能装下完整真实掉落时才退回年龄1；装不下或置块失败均不发物、不溢出丢地。
  行动及续行复核成年、食物模式、模拟居民映射和目标加载/成熟状态；只按本次普通浆果一次结算生产，自定义组件和副产物保持真实物品。

- **指定马铃薯田**：主手空手潜行右击已经种下的马铃薯，可标记或取消该处作物；点击已标记作物下方的耕地也可取消。
  成年居民缺粮或觅食储备不足时，可在附近收获标记的成熟马铃薯，预留一颗原地补种，净产物沿用公仓食物体系。
  背包必须完整装下本次净掉落；毒马铃薯等副产物保留，不计作粮食。本功能不耕地、不自动种空田、不催熟；原版农民AI仍按原版规则运行。

- **逐羊许可与真实剪毛**：管理员按羊UUID预览确认许可；村民可在白床缺羊毛时空手到公仓借用真实剪刀，追踪获准白羊剪毛，再将实际产物和剩余剪刀返仓。途中和下剪前重查保护区，不默认征用附近牲畜，不替换私人装备。管理员可在死亡现场[清算有证据的剪刀借据](docs/dead-shears-reclaim.md)，自行带回公仓；详见[剪毛劳动与边界](docs/livestock-shearing.md)。
- **木板、门、羊毛与床的工作台实体生产**：建筑缺料时，村民先到公仓领料，背包携带到工作台加工，再实际返仓。一根普通橡木制四木板，六块普通木板制三扇门，四线织一白羊毛，三白羊毛加三木板制一张白床。多种输入必须各自完整，中断留料、满仓保留余量，个人材料不征用。羊毛仅补下一张缺料床，线仍需外部供应。当前仅这四种配方，其他建材和工具仍有旧路径；详见[工作台生产物流](docs/workbench-production-logistics.md)。

- **旧石器时代生产**：潜行右击原木可标记采木点，右击石头或圆石可标记采石点；
  再次潜行右击可取消。潜行右击工作台可指定打制台。村民会实际前往采集，
  用 1 原木制作 8 木棍，再用 3 圆石和 2 木棍制作并装备石镐，之后以更高效率采石。
  村民按个人背包与公仓的总可用量判断需求，并领取缺少的公共材料，因此第一把石镐也不要求私人预先占有全部原料。
  个人制棍和磨石会预先核对扣料后的整批产物空间，可利用最后一份原料腾出的格子；放不下时保留原料等待。

- **公共住宅施工与床位**：有床位缺口且没有旧工程时，新住宅在原创北向前廊 `timber_porch_cabin_v1` 与东向侧廊 `timber_side_porch_cabin_v1` 中选一款：均7×7占地、最高5格、错落木顶和两张床，共154个逐块步骤。当前登记床位0/1选北廊、2/3选东廊、4/5回到北廊，依此重复；手动登记或移除床位也会影响尚未开工的下一款，不是已建房屋计数。
  仓库须备齐122橡木木板、24橡木原木、1橡木门、2白床和2火把；居民逐块扣料，缺料保留进度。若全部从原料加工，单栋需要59橡木原木、6白色羊毛、1煤或木炭，完成后余2木板、2门、2火把、7木棍；营火和其他生产另计。
  工地取钟周围6/12/18格四向候选，先遍历同高12点，再依次检查高一格、低一格，总至多36点；要求完整地基、建筑包围体净空和门外可站立；每次仅一个工程，不挖地、不覆盖玩家建筑。`/coop settlement construction sites` 可先查原因。参考图只用于原创形体启发，没有加入瀑布、屋顶泳池或未支持的楼梯/灯笼。
  新住宅选址失败后，同聚落同蓝图在20个游戏tick内不重复扫描；恢复地形后等冷却结束及居民下一次合资格尝试。手动sites查询始终即时，不缓存可建结果；这不是全服性能预算，详见[选址成本评估](docs/construction-survey-cost.md)。
  已保存的石屋和两款木屋工程继续各自原蓝图和指纹，不随床位变化换型、换地或改进度；旧石屋与北廊木屋资源仍保留。两张床在完成后经现有床位登记规则计入容量，不新增人口。主手空手潜行右击完整床可登记现有住房；已加载床被拆后恢复补建需求，未加载床不误删。
  床位仍代表居住使用权。指定工作台支持木板、木棍、门、床、火把和营火，白羊毛可直接供应，或向公仓提供每份4线供村民编织；线和燃料仍需外部取得。自动回归验证静态布局、材料及进度，真实寻路、落块、门床行为和视觉仍待实机验收。
  施工接近点会在6格实际触及范围内寻找地面站位，脚、头与支撑先检查边界及加载状态；同一目标每20tick最多尝试8条路径，失败后轮换，不再盲试目标上方。候选与寻路有界，不代表复杂地形一定可达，也不会搭脚手架。
  当公共仓库缺少直接搭屋的结构原木，居民进入采集阶段时会优先寻找现有12格范围内已标记、可采的橡木，即使没有工作台；加工用木料仍需工作台。背包缴纳沿用原有轮转，私人抽象库存不算公共建材，羊毛和燃料仍需供应。

- **磨制石镐**：潜行右击切石机可指定磨制石台。已有普通石镐的村民会从仓库领取缺少的
  原料，把圆石逐块研磨成平滑石头，再用 3 平滑石头与 2 木棍把石镐升级为效率 I、耐久 I 的
  磨制石镐。升级保留原工具的名称、其他附魔、自定义组件和已有损伤，不降低更高级附魔，也不附赠修理；显式移除附魔组件的特殊工具不会被强行改写。工具制作、研磨和强化都消耗真实材料，建材不会直接变成工具。

## 本地开发

构建需要 JDK 25（当前 Fabric Loom 要求），模组本身按 Java 21 编译、在 Java 21 上运行。推荐 IntelliJ IDEA，并把它设置成用 JDK 25 跑 Gradle。

Mac 上用 Homebrew 装的 JDK 25：

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@25/libexec/openjdk.jdk/Contents/Home
```

```bash
./gradlew runClient   # 启动带模组的客户端
./gradlew runServer   # 启动带模组的服务端
./gradlew runGameTest # 启动无界面游戏测试服务器
./gradlew build       # 构建，产物在 build/libs/
```

首次构建会下载 Gradle、Minecraft、映射和依赖，需要几分钟。之后走缓存会快很多。

### 居民自主资源观察（只读候选）

居民会在同一有界扫描中分批记录附近已加载的成熟甜浆果、橡木原木及石头/圆石位置，可用 `/coop settlement observations` 查看，并由 OP 显式抑制或恢复观察。候选显示材料种类及当前保护否决，来源始终未知，本身不授予木石或土豆采集权。木石自动采收另需本营明确许可区，原人工标记保留。保护区内不新增观察，已有历史记录不自动删除。甜浆果实际采摘另须本营显式许可区，保护区始终优先。范围、容量和存档边界见 [资源观察说明](docs/resource-observations.md)。

### 玩家建筑保护区

用 `/coop protect start "我的房子"` 后空手潜行右击两个地面角点，再 `/coop protect confirm`，即可圈定整高度建筑保护区。保护优先于本模组木石、浆果、土豆采收和施工，途中新增也会在实际改块前重验；原版农民、踩踏、机器和间接方块更新不在首版范围。权限、限额、旧档与完整边界见 [建筑保护区说明](docs/player-protection.md)。

### 施工木板实际运输

普通橡木板与门、床共用单件领料：村民先到公仓取料，再携带到工地安装，失败或工程失效保留/退回原物。木屋不再远程消耗公仓木板，建造耗时会增加；定制木板不自动使用，其他建材的物流范围见 [施工取料说明](docs/construction-supply-logistics.md)。

### 安全自主采浆果

在拟授权区域中心执行 `/coop settlement foraging preview 8`，查看本营、范围及完整高度提示后用 `/coop settlement foraging confirm` 确认（OP2）。村民自行寻找区内成熟浆果并预约采摘，不必逐丛标记。旧档未配置时自动采浆果暂停；人工土豆田和已有食物仍保留。撤销、保护区及范围限制见 [安全觅食说明](docs/safe-foraging.md)。


### 明确许可内自主采集木石

OP先用 `/coop settlement gathering preview wood 4` 预览，再 `confirm` 确认。模式可选wood/stone/both，半径1–8，覆盖全部高度且包括玩家放置的同类材料；请先保护不愿拆的建筑与支撑。村民从有限观察候选中自行选点，保护优先、撤销使旧任务失效；不会把UNKNOWN候选自动写成人工标记。旧档默认无许可，完整范围和实物守恒边界见[安全木石采集](docs/safe-material-gathering.md)。
